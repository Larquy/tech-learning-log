# 复杂度分析与三个经典小题

日期：2026-10-27　课程：数据结构与算法

> 这一轮做了几道题，类型不同但方法相通：算复杂度靠求和与函数关系，判结果靠不变量。记录三题的推导与坑。

## 一、时间复杂度：两种套路

**内层上界随外层变化，必须求和**

```c
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++)
        sum++;
```

i 取 1、2、4、…、2^k，内层次数依次是 1、2、4、…、2^k。等比数列求和：

1 + 2 + 4 + … + 2^k = 2^(k+1) − 1

最后一项 2^k ≤ n，所以总和 < 2n。n 变 10 倍，次数也变 10 倍，是 O(n)。

直观记法：等比数列加起来只比最后一项的两倍少一点，所以总量由最后一项决定，而最后一项不超过 n。

**把内层改成 j < n**，内层固定 n 次，外层 log₂n 次，乘积是 O(nlog₂n)。改一个上界，结论就变了。

**循环变量的平方参与比较，往往是开方**

```c
x = 0;
while (n >= (x + 1) * (x + 1)) x = x + 1;
```

退出条件是 (x+1)² > n，即 x ≈ √n，所以是 O(n^(1/2))。这类题不用数次数，直接解方程找循环变量与 n 的关系。

**规律**：i++ 线性 → O(n)；i *= 2 → O(log n)；平方比较 → O(√n)；内层上界随外层变 → 求和，不能乘。

## 二、循环左移 k 位（原地）

要求时间 O(n)、空间 O(1)。

**三次反转**：

```c
void reverse(int A[], int l, int r) {
    while (l < r) { int t = A[l]; A[l] = A[r]; A[r] = t; l++; r--; }
}

void shift(int A[], int n, int k) {
    if (n <= 0) return;
    k = k % n;
    if (k == 0) return;
    reverse(A, 0, k - 1);
    reverse(A, k, n - 1);
    reverse(A, 0, n - 1);
}
```

原理：左移 k 位等于把前 k 个和后 n−k 个两段互换位置、段内顺序不变。两段各自反转后段内逆序，整体再反转一次，段内顺序还原，位置却换了。

手算 {1,2,3,4,5,6}、k=2：先得 {2,1,3,4,5,6}，再得 {2,1,6,5,4,3}，最后 {3,4,5,6,1,2}。

复杂度：三次反转合计扫过 2n 个元素，交换不超过 3n 次，O(n)；只用一个临时变量，O(1)。

两个坑：k 必须对 n 取模，否则 k>n 时越界；n 或 k 为 0 要提前返回，免得出现 reverse(A,0,-1)。

**两种不满足原地要求的写法（了解一下即可）**

临时数组存前 k 个，后段前移，再把 k 个放末尾：时间 O(n)，空间 O(k)。

取模映射到新数组：`tmp[i] = A[(i+k) % n]`，时间 O(n)，空间 O(n)，最好写但最费空间。

题目只要写了原地，这两种都不合格。写代码时主动在注释里标出空间复杂度，比让老师自己发现好。

## 三、豆子问题：不变量法

罐中有 n 颗黑豆、m 颗白豆。每次取两颗：同色则扔掉、放入一颗黑豆；异色则扔掉黑豆、放回白豆。

**先列增减表**

| 取出 | 黑豆变化 | 白豆变化 | 豆子总数 |
|---|---|---|---|
| 两黑 | −1 | 0 | −1 |
| 两白 | +1 | −2 | −1 |
| 一黑一白 | −1 | 0 | −1 |

关键结论：白豆要么不变，要么减 2，所以 **m 的奇偶性始终不变**。

**第一问：必然终止**

每次操作总数净减 1，总数从 n+m 开始，下界为 1，最多 n+m−1 次就只剩一颗，不可能无限进行。

**第二问：何时剩白豆**

只剩一颗时白豆数只能是 0 或 1。由奇偶不变性反推：

m 为奇数 → 最终 m 必为奇数 → 只能是 1 → 剩白豆。
m 为偶数 → 最终 m 必为偶数 → 只能是 0 → 剩黑豆。

与 n 无关，只要 n+m ≥ 1。验证：n=0,m=2 得黑豆；n=1,m=1 得白豆。

## 四、方法小结

复杂度题：单个循环看增长方式，嵌套且内层上界变化就必须求和，绝大多数据此都能算出来。

构造题：找不变量。奇偶、模 3 余数、总和、逆序对数量，这几样最常出现。

原地要求：先确认题目有没有这三个字，再决定用辅助空间还是三次反转。
