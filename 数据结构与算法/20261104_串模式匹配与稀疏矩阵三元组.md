# 串的模式匹配与稀疏矩阵的三元组表示

日期：2026-11-04　课程：数据结构与算法

> 实验03 的收尾和实验04 的开头。前半记 BF 与 KMP 的实现要点，后半记三元组顺序表的类写法。

## 一、BF 朴素匹配

两层循环。外层 i 是假定的起点，从 0 到 n−m。内层 j 逐字符比较 s[i+j] 与 t[j]，相等则继续，不等则 break。

内层 j 走到 m 说明整段匹配，返回 i。外层走完返回 −1。

复杂度最坏 O(nm)，主串指针会后退，已经比过的部分要重比。

## 二、KMP

**改进点**：失配时主串指针 i 不后退，只把模式串右滑，靠 next 数组决定滑多少。

**next 的含义**：next[k] 表示模式串前 k 个字符的最长相等前后缀长度，next[0] 只作哨兵，取 −1。

**递推求法**：已算出 next[i]，推 next[i+1] 时令 j = next[i]，看 t[j] 与 t[i] 是否相等。相等则长度加一，不等则 j 退回 next[j] 再试，直到退成 −1 表示归零。

```
next[0] = -1;
for (i = 0; i < m-1; i++)
    if (i == 0) next[i+1] = 0;
    else {
        int j = next[i];
        while (j != -1 && t[j] != t[i]) j = next[j];
        next[i+1] = j + 1;
    }
```

**匹配过程**：i 扫主串，j 记已匹配长度。相等则双双加一，不等则 j 退到 next[j]。j 等于 m 时匹配成功，起点是 i−m。

复杂度 O(n+m)。

**一个坑**：next 的约定必须两处一致。教材常把下标整体右移一位用 next[1] 起算，若求 next 和用 next 各按一套，匹配结果会错位。

## 三、稀疏矩阵的三元组顺序表

**为什么压缩**：4 行 5 列共 20 个元素，非零只有 6 个，存 20 个浪费，只存非零的。

**结构**：每个非零元素存（行号、列号、值），再配三个整体参数——行数 mu、列数 nu、非零个数 tu。

**存储顺序**：按行优先，行号递增，同行列号递增。按行优先遍历二维数组自然就是这个顺序，不需要额外排序。

**类写法**：Triple 作私有嵌套结构，data、mu、nu、tu 私有，Create 与 Print 作成员函数，外部只能通过接口操作。

```cpp
class TSMatrix
{
private:
    struct Triple { int i, j, e; };
    Triple data[MAX];
    int mu, nu, tu;
public:
    TSMatrix() : mu(0), nu(0), tu(0) {}
    void Create(int a[][5], int r, int c);
    void Print();
};
```

**待做**：转置。普通转置按列扫描，复杂度 O(nu×tu)；快速转置先统计每列非零个数与起始位置，一趟搬完，O(nu+tu)。
