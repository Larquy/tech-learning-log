# 作业1-6 重点题型梳理

日期：2026-10-29　课程：数据结构与算法

> 六次作业（绪论、线性表、栈队列、串、数组与广义表、树）的题型归纳。不抄答案，只写每类题的解法步骤和易错点，考前照着过一遍。

## 一、绪论

**时间复杂度**：把循环执行次数列成求和式。

单层到 n → O(n)。两层独立 → O(n²)。内层上界随外层变（`j<=i`）→ 求和得 n(n+1)/2 → O(n²)。三重矩形嵌套（矩阵乘法）→ O(n³)。`i*=2` → O(log n)。循环变量与平方比较 → O(√n)。

易错：看到嵌套就写 O(n²)，但 `i*=2` 那种外层只跑 log n 次；内层上界随外层变时不能直接相乘。

**概念三连**：数据结构 = (D,S)，S 是 D 上的关系；逻辑结构与存储结构要分开说；顺序存储的物理地址连续且与逻辑顺序一致。

## 二、线性表

选择题固定三个考点：链表结点地址不一定连续；最常用“尾插 + 删尾”选带头结点的双循环链表；在 p 后插入 q，两条赋值顺序不能反（先 `q->next=p->next`，再 `p->next=q`）。

计算：顺序表等概率插入平均移动 n/2 个元素，删除 (n-1)/2。记“插搬 n-i+1、删搬 n-i”现场推。

编程：两个递增链表合并成递减并去重。双指针逐个取较小者，用头插法插入 lc；头插天然把顺序反过来，相同值跳过。

## 三、栈和队列

**出现频率最高：出栈序列合法性**。模拟法：按入栈序列压栈，与出栈序列逐位比对，栈顶匹配就弹出，不匹配就继续压，最后栈空即合法。

配套结论：n 个元素的不同出栈序列数是卡特兰数；栈容量受限时，看“先出的大元素”后面是否还满足逆序关系。

**循环队列**：入队 `rear=(rear+1)%MAX`，出队 `front=(front+1)%MAX`；队空 `front==rear`；队满 `(rear+1)%MAX==front`，所以实际最多存 MAX-1 个。给 front/rear 算操作后的值，一律手画环形图推。

链栈空的条件是 `TOP==NULL`；`TOP->next==NULL` 是带头结点时的说法，两者别混。

递归转非递归要设置栈，因为递归本质是保存现场。

## 四、串

**最易丢分：KMP 的 next / nextval 手算**。

next 定义是“最长相等前后缀长度 + 1”，约定 `next[1]=0`。nextval 在 next 基础上优化：若 `s[i]==s[next[i]]`，则 `nextval[i]=nextval[next[i]]`，否则沿用 next。

手算技巧：先算每个位置不含自身的最长公共前后缀长度，再加 1。

比较次数题只能把匹配过程走一遍数出来，没有捷径。

字符各不相同时，非空真子串个数 = n(n+1)/2 − 1。

## 五、数组与广义表

广义表只考两点：Head 取第一个元素（可能是原子也可能是子表）；Tail 取剩余部分组成的表，**一定带括号、可能为空表**。所以剩余一个元素时要写成 `((x))`，两层括号。

稀疏矩阵三元组：按行优先、行内列号递增；列号是全局列号，不是行内序号。表头记 (行数, 列数, 非零个数)。

马鞍点：先求每行最小值、每列最大值，再逐元素比对，O(n²)。注意可能无解、可能多解，代码里要有“没找到”的分支。

## 六、树

**前序 + 中序还原**：前序第一个是根，在中序里切开左右两段，递归处理，最后按“左右根”输出后序。

**三种表示互换**：后序即逆波兰式，中序即原式；画表达式树时注意同级左结合（`a*b/c` 是 `(a*b)/c`）。

**完全二叉树计数**：`n0=n2+1`；N 为偶数时 `n1=1`、`n0=N/2`；N 为奇数时 `n1=0`、`n0=(N+1)/2`。一般树用 `n0 = 1 + Σ(i−1)·ni`。

**哈夫曼**：每次取两个最小权值合并，WPL = Σ(权值×深度)，可用“所有非叶结点权值之和”验算，两种算法结果必须一致。

**线索化空链域**：先序线索化后剩 1 个（最后一个结点的右域），中序剩 2 个。

## 七、只复习三块也够用

时间排序的话，优先这三类，各占一道大题且都靠动手熟练：

KMP 的 next 手算；二叉树前中序还原求后序；栈的出栈序列合法性判定。

## 八、易错清单

时间复杂度只看嵌套层数，忽略 `i*=2` 这类非线性推进。
插入两条赋值写反，链表断成两截。
循环队列表满条件少一个 `%MAX`。
KMP 的 next 从 0 开始还是从 1 开始，跟着教材约定，别半途换。
广义表 Tail 忘记加外层括号。
二叉树还原时把“前序第一个是根”用成了“中序第一个”。
哈夫曼合并忘记把新结点放回集合重新排序。
顺序表删除时边删边搬，下标错乱（应双指针压缩）。
