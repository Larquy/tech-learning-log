# 单链表反转 & 两个递增链表合并为递减链表

日期：2026-09-21　科目：数据结构与算法

## 结论先行

- **单链表反转**：三指针迭代（prev / cur / next），一次遍历，O(n) 时间 O(1) 空间。
- **两个递增链表合并为递减（去重）**：归并取较小者 + **头插**（头插天然产生逆序）+ 与结果表头比较去重。

## 1. 单链表原地反转

```c
LNode *Reverse(LNode *head) {
    LNode *prev = NULL, *cur = head->next, *nxt;
    while (cur) { nxt = cur->next; cur->next = prev; prev = cur; cur = nxt; }
    head->next = prev;          /* 头结点接回新首结点 */
    return head;
}
```
要点：**先存后继再改指针**，否则断链。

## 2. 合并两个递增链表为递减（相同值只留一个）

```c
void Merg(LinkList la, LinkList lb, LinkList &lc) {
    LNode *p = la->next, *q = lb->next;
    lc = la; lc->next = NULL;
    while (p && q) {
        if (p->data < q->data)      { 摘 p → 头插 lc; p = p->next; }
        else if (p->data > q->data) { 摘 q → 头插 lc; q = q->next; }
        else                        { free(q); 摘 p → 头插 lc; p = p->next; q = q->next; }
    }
    while (p) { 摘 p → 头插 }       /* 剩余必须逐个头插 */
    while (q) { 摘 q → 头插 }
    free(lb);
}
```
头插函数（带去重）：
```c
if (lc->next && lc->next->data == e) { free(s); return; }   /* 重复丢弃 */
s->next = lc->next; lc->next = s;
```

**实测输出**
```
la=(1,3,5,7) lb=(2,3,6,8) → lc=(8,7,6,5,3,2,1)
la=(1,1,2)   lb=(1,2,3)   → lc=(3,2,1)     ← 表内 + 跨表重复都去掉
la=()        lb=(4,5)     → lc=(5,4)
```

## 3. 踩的坑

1. **剩余部分不能整串接上** —— 剩下的本身递增，接上去会破坏递减，要逐个头插。
2. **去重不能只比 p 和 q** —— 表内可能有重复，判断标准是"与**结果表头**比较"。
3. **`LinkList &lc` 是 C++ 引用** —— 声明成 `&` 就得存 `.cpp` 用 g++ 编；纯 C 要改成 `LinkList *lc`。

## 4. 顺序表 vs 链表（一并记住）

| | 顺序表 | 链表 |
|---|---|---|
| 存储 | 连续，需预估容量 | 不连续，动态申请 |
| 存取 | **随机存取 O(1)** | 顺序存取 O(n) |
| 插/删 | 要移动元素，平均 n/2 次 | 只改指针 O(1)（找位置仍 O(n)） |

## 5. 还没搞懂的

- 双向循环链表在"尾插 + 尾删都要 O(1)"时，尾指针该怎么维护最省事。
