# 存储器写周期时序、最大组态与 PC 总线标准

日期：2026-10-20　课程：汇编语言与微机接口

> 本篇按课堂顺序整理：存储器写周期的 T1 到 T4 → 读周期与 I/O 读写的差异 → 取指与数据存取的区分 → 最大组态下的引脚重定义 → 8288 的工作方式 → PC 总线 62 线规范 → 课堂练习反馈。文末列出三处与数据手册不一致的地方，考前值得对一遍。

## 一、存储器写周期：T1 到 T4

一个写周期四拍，每拍各管一件事。

| 拍 | 核心任务 | 关键动作 |
|---|---|---|
| T1 | 给地址 | 复用线 AD0 到 AD7、非复用线 A8 到 A19 送出 20 位物理地址；ALE 有效锁存；状态信号有效 |
| T2 | 给数据、开写 | AD0 到 AD7 切成数据；DEN 有效使能缓冲器；DT/R 指明方向；WR 变低 |
| T3 | 查就绪 | 采样 READY，无效就插 Tw |
| T4 | 收尾 | 数据已锁存，控制信号依次撤销 |

### T1：地址与锁存

地址在 CPU 内部算好，通过 AD0 到 AD7 和 A8 到 A19 一起送出去，凑成 20 位，也就是 1MB 的寻址空间。

ALE 在 T1 前沿有效，作用是把地址打进外部锁存器（8282 或 74LS373）。为什么必须锁：**复用线上的地址只在 T1 有效**，T2 前沿它就变成数据了，没有锁存器，后端就不知道刚才那个地址是什么。

有一处要分清：**非复用的 A8 到 A19 在整个总线周期内都保持有效**，只有 AD0 到 AD7 是分时的。所以有的资料说"地址只在 T1 存在"，指的是低 8 位。

状态信号 SS0、IO/M、DT/R 在 T1 期间也有效，三个一起编码出当前是哪种总线操作。

### T2：数据与写控制

AD0 到 AD7 从地址模式切成数据模式，待写的数据被放上总线。

DEN 有效，使能外部双向缓冲器（8286 或 74LS245），把 CPU 的数据引脚和系统数据总线接通。

DT/R 指示方向，写操作时为高，表示从 CPU 往外发。

WR 在 T2 前沿变低，作为写操作的启动信号。要注意的是，真正送进存储芯片的写信号不是 WR 本身，而是 WR 和 IO/M 经外部逻辑组合出来的结果。

### T3：查 READY

CPU 在 T3 前沿采样 READY，判断存储芯片或 I/O 接口有没有准备好。

READY 无效就在 T3 和 T4 之间插入一个或多个 Tw，一直到 READY 有效才进 T4。

READY 由外部器件发，所以它和 CPU 时钟是异步的，需要 8284 同步之后再送进来。这也解释了为什么有些慢速存储器接上之后程序能跑但速度明显下降——它一直在插 Tw。

### T4：完成写入

写操作在 T4 前沿完成，此时数据已经被外部存储单元锁存。

控制信号在 T4 前沿撤销，地址信号在 T4 结束后撤销。

**撤销顺序有讲究**：先撤写控制信号，再断开数据总线，最后撤地址。顺序反了，比如地址先变、写信号还低，就可能把数据写到错误的单元里去。

## 二、读周期与 I/O 读写的差异

### 存储器读

T1 和写周期一样，送地址、锁存。

T2 时 DT/R 变低，表示数据往 CPU 里走；DEN 有效，但 **AD0 到 AD7 处于高阻**，等外部把数据送上来。这一点和写周期正好相反：写是 CPU 驱动总线，读是 CPU 让出总线等别人驱动。

RD 在 T2 前沿有效，和 IO/M 组合生成存储器读选通。

T4 前沿 CPU 从总线上取走数据，锁进内部寄存器。

### I/O 写与 I/O 读

区别只在 IO/M 这一根线：I/O 周期里它是高电平，于是组合出来的是 IOWC 而不是存储器写，是 IORC 而不是存储器读。

IOWC 是广播信号，所有 I/O 设备都能收到，但只有地址匹配的那个端口会响应。这一点常被误解成"I/O 写是点对点的"，其实是广播加地址译码。

## 三、取指与取数的区分

两者在总线时序上几乎一样，都是读操作，差别在段来源和状态编码：

| | 地址来源 | 状态编码 |
|---|---|---|
| 取指令 | CS:IP | 与数据读不同（SS0 或 S2S1S0 对应"取指"） |
| 存取数据 | DS 或 SS + 偏移 | 对应"读存储器" |

外部正是靠 T1 的状态编码区分这两种读：一个是读代码段取指令，一个是读数据段取操作数。8288 据此生成不同命令，外部调试设备也能靠这个看出 CPU 在干什么。

## 四、最大组态下的引脚重定义

MN/MX 接高是最小组态，CPU 自己产生全部控制信号；接低是最大组态，部分引脚改用途，支持多主控的总线系统。

| 最小模式 | 最大模式 | 最大模式下的作用 |
|---|---|---|
| HOLD | RQ0/GT0 | 总线请求/授权，通道 0 |
| HLDA | RQ1/GT1 | 总线请求/授权，通道 1 |
| WR | LOCK | 总线锁定，屏蔽外部总线请求 |
| IO/M | S2 | 状态码 |
| DT/R | S1 | 状态码 |
| DEN | S0 | 状态码 |
| ALE | QS0 | 指令队列状态 |
| INTA | QS1 | 指令队列状态 |

几点说明：

**RQ/GT 是双通道**。最小模式只有一根 HOLD 一根 HLDA，最大模式给两路，可以挂两个独立的总线主控。它用负脉冲握手，同一根线兼顾请求和响应，靠分时复用实现双向。

**LOCK 的作用是保原子性**。有效期间 CPU 不理外部总线请求，防止 DMA 之类的操作插进来打断关键代码段。

**S0、S1、S2 是三位状态码**：000 中断响应、001 读 I/O、010 写 I/O、011 暂停、100 取指、101 读存储器、110 写存储器、111 空闲过渡。

**QS0、QS1 反映指令队列状态**：空、满、部分填充、正在取指。这是给外部协处理器（比如 8087）用的，它需要知道 CPU 现在取到哪了，才能同步执行。

## 五、8288 的工作方式

### 状态译码

8288 接收 S0、S1、S2，内部译码出当前是哪一种总线周期，然后产生对应命令：

MEMR、MEMW、IOR、IOW，加上两个"超前"版本 AMWC（超前存储器写）和 AIOWC（超前 I/O 写），以及 INTA。

超前写比普通写早一拍有效，用在边沿触发的外设上；普通写维持整个 T2 电平，用在电平触发的器件上。

### ALE 与 DEN

8288 没有内部时序电路，它不知道现在是 T1 还是 T2。它的判断依据是状态码的变化：**从 111（空闲过渡）跳到任何一个有效状态，就认为 T1 开始**，于是发 ALE。

DEN 在 T2 前沿输出，控制数据缓冲器使能；DT/R 同样根据状态码生成。

### 总线仲裁

8288 的 AEN 和 CEN 两个输入端接 DMA 控制器的 AEN。

DMA 接管总线时 AEN 有效，8288 的全部输出置高阻，避免和 DMA 抢驱动。

只有 CPU 掌握总线、AEN 无效时，8288 才正常输出。这就是"总线单一主控"原则的硬件实现：同一时刻只允许一个设备驱动总线。

## 六、PC 总线 62 线标准

### 地址与数据物理分离

D0 到 D7 是 8 位双向数据线，A0 到 A19 是 20 位单向地址线，在插槽上物理分开，不复用。

8088 内部 AD0 到 AD7 明明是复用的，但 PC 总线把这一层封装掉了：板载锁存器把地址锁住，对外呈现成独立的总线。所以写扩展卡的人不用关心复用时序。

ALE 在 PC 总线上还留着，但作用变了：不再用于锁存地址（板上已经锁好了），而是用来标识一个总线周期的起点。

### 读写控制信号

MEMR、MEMW、IOR、IOW 四个都是低电平有效，由板载逻辑根据 CPU 状态生成。

这层封装的价值在于：扩展卡不需要知道 CPU 工作在最小还是最大组态，也不需要知道内部怎么组合信号，只要按标准电平和时序来就行。

还有一根 I/O 通道就绪信号（PC 标准里叫 I/O CH RDY，对应 CPU 的 READY），扩展卡拉低它就能让 CPU 插 Tw，慢速卡靠它工作。

### 中断资源分配

IRQ2 到 IRQ7 开放给扩展卡，高电平有效。IRQ0 和 IRQ1 没引到插槽上：

- IRQ0 归 8253 定时器，约每 55ms 触发一次，操作系统的时间片调度靠它
- IRQ1 归键盘控制器，按键时触发

所有 IRQ 经板载 8259 仲裁，最后只向 CPU 提交一根 INTR。

### DMA 相关

DREQ0 到 DREQ3 是四路 DMA 请求，DACK0 到 DACK3 是对应响应。

TC（Terminal Count）在计数归零时由 8237 输出，通知外设这一批传完了。

AEN 在 DMA 期间有效，作用就是前面说的，把 8288 这类 CPU 附属芯片的输出置高阻。

### 时钟与电源

OSC 是 8284 输出的原始高频时钟，约 14.318MHz；CLK 是它三分频后的 4.77MHz 系统时钟。

电源提供 +5V、-5V、+12V、-12V 和地。

## 七、课堂练习反馈

**读操作时序的顺序**：投票里 17% 的人认为 CPU 先检测 READY 再发读信号，实际顺序相反。正确是 T2 发 RD，T3 前沿才采 READY 决定插不插 Tw。老师明确说这是期末重点。

**中断引脚**：不少人以为 8086 只能从 INTR 收中断，漏了 NMI。NMI 不受 IF 屏蔽，处理电源故障这类紧急事件用。PC 总线上 NMI 同样保留。

## 八、三处值得对一遍的地方

整理时对照 8088 数据手册，有三处和笔记里的说法不完全一致，考前值得再核一下老师的口径。

**一是 SS0 的编码**。笔记写"SS0=1 表示存储器写操作"，但数据手册的状态表里，写存储器是 IO/M=0、DT/R=1、SS0=0；SS0=1 配 DT/R=1 是"过渡状态"。按手册，存储器写时 SS0 应为 0。

**二是 8288 的两个使能脚名字**。笔记写 CMDEN 和 AEN，8288 实际的引脚是 CEN（Command Enable，命令使能）和 AEN（Address Enable，地址使能）。功能描述没问题，就是名字简写混了。

**三是就绪信号的名称**。PC 总线插槽上那根叫 I/O CH RDY，"IORDY"是后来 IDE/ATA 接口上的叫法。两者作用一样，但标准名称不同。

这三处不影响理解整条时序，但如果考试填空写名字，按手册的写法更稳。
