## 三、指定功能 1：分离 VAR1=35H 的高/低 4 位

要求：高 4 位、低 4 位分别作为低 4 位存入 RES1、RES2，两变量高 4 位为 0。

```asm
    MOV AL, VAR1
    AND AL, 0FH          ; 掩码：只留低 4 位 → 05H
    MOV RES2, AL
    MOV AL, VAR1
    MOV CL, 4
    SHR AL, CL           ; 逻辑右移 4 位 → 03H
    MOV RES1, AL
```

**分析**：
- `AND AL,0FH`：高 4 位清 0 ✓ 结果 **05H**；**CF=OF=0**、SF/ZF/PF 按结果、**AF 无定义**。
- `SHR AL,CL`：逻辑右移 4 次 ✓ 结果 **03H**；**CF = 最后移出的位 = 原 bit3 = 0**；移位次数 >1 必须用 CL。
- 若用 `SAR` 会保留符号位 ✗ 结果可能错 —— 所以必须用 `SHR`。

## 四、指定功能 2：32 位数据 VAR2=0E2597455H 算术左移 2 位

```asm
    MOV AX, WORD PTR VAR2         ; 低 16 位
    MOV DX, WORD PTR VAR2+2       ; 高 16 位（+2，不是 +1）
    MOV CL, 2
    SAL AX, CL                    ; 低字左移：移出的最高位 → CF
    RCL DX, CL                    ; 高字带进位左移：CF → 最低位
    MOV WORD PTR VAR2, AX
    MOV WORD PTR VAR2+2, DX
```

**原理**：32 位左移不能只移一个寄存器 → **低字 SAL + 高字 RCL**，用 **CF 当接力棒**；顺序是**先低后高** ✓（右移相反，先高后低）。高字若用 SHL 代替 RCL，进上来的位会丢 ✗ 结果错。
**结果**：E2597455H × 4 = 3_8965D154H → 超出 32 位，保留低 32 位 = **8965D154H**；**CF=1**。
**溢出分析**：移位中共有 2 位被移出 32 位之外（原 bit31=1、bit30=1），**CF 最终记录的是原 bit30 = 1** → CF=1 说明"有非零的有效位被移出" → 结果丢失高位信息，即**溢出**。若把 2 位拆成两次 1 位移位，第二轮时符号位发生变化 → **OF=1**，同样判定为溢出。

## 五、程序编制四步（报告第 2 条要写）

1. **编辑**：任意文本编辑器，后缀必须是 `.ASM`
2. **汇编**：`MASM X.ASM;` → 生成 `X.OBJ`（0 Warning / 0 Severe Errors 才算成功）
3. **连接**：`LINK X.OBJ;` → 生成 `X.EXE`
4. **调试**：`DEBUG X.EXE` → 用 R / T / D / G 观察

**DEBUG 要点**：进 DEBUG 后**先单步走完 `MOV AX,DATA`、`MOV DS,AX`**（否则 DS 不是数据段，D 命令看到的不是你的数据）；用 `D DS:0` 验证内存；`G` 全速跑；`Q` 退出。

## 六、易错点

1. 右移用 `SHR`（逻辑）✗ 用 `SAR` 会保留符号位。
2. 移位次数 >1 必须放 **CL**。
3. `WORD PTR VAR2+2`：高字偏移是 **+2**，不是 +1。
4. **RCL 只影响 CF 和 OF**，SF/ZF/PF/AF 不变（与 SAL 不同）。
5. **EXE 打开时 DS 不是自己的数据段** —— 必须先走完 DS 初始化两条指令。
