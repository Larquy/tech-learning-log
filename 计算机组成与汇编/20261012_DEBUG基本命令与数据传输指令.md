# DEBUG 基本命令与数据传输指令（课程设计 · 第一次实验）

日期：2026-10-12　课程：汇编语言与微机接口（MASM + DOSBox）

> 课堂讲义整理版。核心是两件事：**DEBUG 怎么用** + **指定程序片段每条指令干了什么**。

## 一、实验目的

- 熟练掌握 **DEBUG 的基本调试命令**，能用它编写、调试汇编程序片段。
- 在理解**数据传输指令**的基础上，对指定程序片段调试并记录。

## 二、实验报告要求（老师明确提的）

1. 说明所学 **DEBUG 基本命令的使用方法**。
2. **记载每条指令执行后，寄存器、标志位的变化情况**，并解释指令执行原理。

## 三、本次实验指定的程序片段

```asm
        MOV  AL, 01H
        MOV  SI, 0002H
        LEA  SI, [SI]
        MOV  BYTE PTR [SI], 80H
        LAHF
        XCHG AL, AH
        SAHF
        XCHG AH, [SI]
        SAHF
```

### 逐条要点（写报告时对着记录）

| # | 指令 | 关键点（要观察什么）|
|---|---|---|
| 1 | `MOV AL,01H` | AL ← 01H；**MOV 不影响任何标志位** ✓ |
| 2 | `MOV SI,0002H` | SI ← 0002H ✓ |
| 3 | `LEA SI,[SI]` | **取的是"有效地址"不是内容** ✓ → SI 仍 = 0002H（LEA 与 MOV 的区别是本次重点）|
| 4 | `MOV BYTE PTR [SI],80H` | 把 80H 写进 **DS:0002** 那个字节 → 改的是**内存**，不是寄存器 ✓；`BYTE PTR` 必须写 ✗ |
| 5 | `LAHF` | 把**标志寄存器低 8 位 → AH** ✓（标志位本身不变 ✓）|
| 6 | `XCHG AL,AH` | AL 与 AH **互换** ✓（原来进 AH 的那个值被换到 AL）|
| 7 | `SAHF` | 把 **AH → 标志寄存器低 8 位** ⚠️ **这条改标志位** |
| 8 | `XCHG AH,[SI]` | AH 与内存 DS:0002 互换 → **AH 拿到 80H** ✓ 内存变成 01H ✓ |
| 9 | `SAHF` | 再把 AH(80H) 写进标志位 ⚠️ 标志位大改（**SF/ZF/AF/PF/CF 一起变**）|

## 四、DEBUG 常用命令（本次学了 r / a / u / t）

| 命令 | 功能 | 用法 |
|---|---|---|
| **r** | 查看 / 修改**寄存器内容与标志位** | `-r`　`-r寄存器名`（**名称前不加空格**）|
| **a** | 从键盘输入**汇编指令**，DEBUG 自动转成机器码存入内存 | `-a`　`-a xxxx:xxxx` |
| **u** | **反汇编**：把机器码还原成汇编指令显示 | `-u`　`-u xxxx:xxxx` |
| **t** | **单步执行**下一条指令，执行完自动暂停并回显寄存器 | `-t` |
| （补充）q | 退出 DEBUG | `-q` |
| （补充）d / e | 显示 / 修改内存字节 | `-d`　`-e` |
| （补充）g | 连续运行（可给断点） | `-g` |

- 进入：命令行输入 `DEBUG` ✓ → 提示符是**短横线 `-`** ✓
- 退出：`-q` ✓ → 回到 DOS 提示符 ✓
- Windows 下的 DEBUG 跑在 **8086 虚拟机**里 ✓（不代表真实 CPU 是 8086 ✓）

## 五、DEBUG 与源程序的重要区别（考点）

| | DEBUG 里 | 源程序里 |
|---|---|---|
| 数据进制 | **只能用十六进制** ✗（十进制等一律不行）| 可以**混用**各种进制 ✓ |
| 变量名 / 伪指令 | ❌ 没有（直接给地址和指令）| ✅ 有 |

## 六、a 命令的修改规则（老师特别讲的）

- 新指令**比原来短** → 后面自动补 **NOP**（单字节空操作）✓
- 新指令**比原来长** → **从该指令起的后续指令全部要重新录入** ✗
- 所以 **a 命令只适合输入较短的程序片段** ✓

## 七、五个易错点

1. `-rAX` **不要写成** `-r AX`（寄存器名前不加空格）✗
2. `u xxxx:xxxx` 的**起始地址必须给准** ✗，否则整段反汇编"牛头不对马嘴" ✓
3. DEBUG 里输入的数字**一律按十六进制解释** ✗
4. a 命令里**逻辑错误（语法对但意思错）DEBUG 不会提示** ✗ → 只能退出后重新定位修改 ✓
5. `MOV [SI],80H` 不写 `BYTE PTR` 会报**操作数类型不明确** ✗
