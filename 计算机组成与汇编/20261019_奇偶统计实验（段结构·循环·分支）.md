# 实验：统计数组里的奇数和偶数个数（段结构、循环与分支）

日期：2026-10-19　课程：汇编语言与微机接口

## 一、题目

数据段给出 10 个字节：`14,-25,66,-17,78,-33,46,-96,71,80`，统计其中奇数和偶数的个数，分别存进 `ODDNUM` 和 `EVENNUM`。

## 二、程序结构

```asm
DATAS SEGMENT
    VARB    DB 14,-25,66,-17,78,-33,46,-96,71,80
    ODDNUM  DB 0
    EVENNUM DB 0
DATAS ENDS

STACKS SEGMENT
    DW 40H DUP(0)
STACKS ENDS

CODES SEGMENT
    ASSUME CS:CODES, DS:DATAS, SS:STACKS
START:
    MOV AX,DATAS
    MOV DS,AX

    LEA SI,VARB
    MOV CX,10
    MOV BX,0

L1: MOV AL,[SI]
    TEST AL,1
    JZ  EVEN1
    INC BL
    JMP NEXT
EVEN1:
    INC BH
NEXT:
    INC SI
    LOOP L1

    MOV ODDNUM,BL
    MOV EVENNUM,BH

    MOV AH,4CH
    INT 21H
CODES ENDS
END START
```

结果：奇数 4 个、偶数 6 个，数据段末尾是 `04 06`。

## 三、这次的坑

**把 EVEN 当标号，报 syntax error: EVEN**
`EVEN` 是 MASM 的伪指令，用来把地址对齐到偶数边界，属于保留字，不能做标号。改成 `EVEN1` 就好了。同类别再避开 `BYTE`、`WORD`、`TYPE`、`LENGTH`、`SIZE`、`NEAR`、`FAR`、`PTR`、`OFFSET`、`SEG`、`MOD`。

**`LEA SI,VARB` 和 `MOV SI,VARB` 不是一回事**
`LEA` 取的是偏移地址，`MOV SI,VARB` 会把数组第一个字节的内容 0EH 读进 SI。

**`INC SI` 只能写在分支汇合的地方**
写在两条分支里各一份，容易漏改或者重复执行。

## 四、DEBUG 验收

1. 汇编、链接后用 DEBUG 载入
2. `U` 往下翻，找到 `MOV AH,4CH` 那行的偏移
3. `G 0019` 让程序停在返回 DOS 之前
4. `D DS:0` 看数据段：前十个字节是 `0E E7 42 EF 4E DF 2E A0 47 50`，后面两个是 `04 06`

两个细节：不要在程序返回 DOS 之后再 `D`，那时 DS 已经被 DOS 改回去，看到的不是自己的数据段；调试到 `INT 21H` 要用 `P` 不要用 `T`，`T` 会跟进中断处理代码里出不来。

## 五、要点清单

1. 段寄存器不能直接送立即数，必须经通用寄存器中转：`MOV AX,DATAS` 再 `MOV DS,AX`
2. 三段结构：`DATAS`、`STACKS`、`CODES`，`ASSUME` 里把 CS、DS、SS 写全，最后 `END` 跟入口标号
3. 循环四件套：`SI` 指数组、`CX` 放次数、`LOOP` 自动减一并判断、`INC SI` 只在汇合处写一次
4. `LOOP` 的跳转距离只有 -128 到 +127 字节，循环体太长会跳不到
5. 分支的固定套路：先 `CMP` 或 `TEST` 产生标志位，再按**相反条件**跳到另一分支，then 段末尾补一条 `JMP` 跳过 else
6. `TEST` 保留操作数、只置标志位，`AND` 会改操作数；判断最低位用 `TEST AL,1`，判最高位用 `TEST AL,80H`
7. 负数不用特殊处理，补码的最低位照样能判奇偶：-25 存成 E7H，最低位是 1
8. `MOV BX,0` 一条就同时清 `BL` 和 `BH`，比写两条省事
9. 存结果时 DS 必须还指向数据段，中途改过 DS 的话要先改回来
