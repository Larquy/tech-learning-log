# DEBUG 单步调试与标志位

日期：2026-09-18　课程：汇编语言与微机接口

## 结论先行

- **`LAHF`**：标志寄存器低 8 位 → AH；**`SAHF`**：AH → 标志寄存器低 8 位。
- **`INC` / `DEC` 不影响 CF**（为了不破坏多字节加减的进位链）。
- **逻辑运算（AND/OR/XOR/TEST）固定让 CF = OF = 0，AF 无定义。**

## DEBUG 常用命令

| 命令 | 作用 | 关键点 |
|---|---|---|
| `R` | 看/改寄存器与标志位 | `R` 全部；`R AX` 改单个；`RF` 改标志 |
| `U` | 反汇编 | 起始地址要给准 |
| `T` | 单步（**会进 CALL/INT**） | `T 5` 连走 5 条 |
| `P` | 单步（跳过子程序/中断） | 调 `INT 21H` 用它 |
| `D` | 显示内存 | `D DS:0` 看数据段 |
| `G` | 运行到断点 | 断点要设在指令首字节 |
| `A` | 录入汇编 | 语法错不生成机器码；逻辑错要退出 A 重录 |
| `Q` | 退出 | **不保存** |

**两个必记**：DEBUG 里数字**默认十六进制**；`Q` 退出**不存盘**。

## 标志位怎么定（ADD/SUB）

| 标志 | 含义 |
|---|---|
| CF | 无符号数：最高位向外进位/借位 |
| OF | 有符号数：两操作数同号且结果变号 |
| AF | 低 4 位是否进位/借位 |
| ZF / SF / PF | 结果为 0 / 最高位为 1 / 低 8 位中 1 的个数为偶 |

**例**：`64H + 79H = DDH` → CF=0（没超 FFH）、AF=0、**OF=1**（+100 加 +121 超 +127）、PF=1（6 个 1）、SF=1。
**例**：`64H − 79H = EBH` → CF=1（借位）、**AF=1**、OF=0、PF=1、SF=1。

## 单步跟踪实例（LAHF/SAHF/XCHG 那段程序）

| 步 | 指令 | 关键变化 |
|---|---|---|
| 4 | `MOV BYTE PTR [SI],80H` | 内存 0002H ← 80H |
| 5 | `LAHF` | 标志位 → AH |
| 6 | `XCHG AL,AH` | AL、AH 互换 |
| 7 | `SAHF` | 装入 01H → **CF=1**，其余清零 |
| 8 | `XCHG AH,[SI]` | AH ← 80H，内存 ← 01H |
| 9 | `SAHF` | 装入 80H → **SF=1**，其余清零 |

## 踩的坑

1. **`POPF` 会一次性改掉全部标志位（含 IF）**，实模式下相当于悄悄开关中断。
2. 8086 **没有直接给 FLAGS 赋值的指令**，只能走栈（`PUSHF`/`POPF`）或 `LAHF`/`SAHF`（只搬低 8 位）。
3. **`PUSH` 立即数在 8086 上是非法指令**（80186 才有）；`SHR BL,3` 同理（次数只能是 1 或 CL）。

## 还没搞懂的

- TF（陷阱标志）在单步调试里由 DEBUG 自己管，还是程序也能改，实际影响哪些行为。
