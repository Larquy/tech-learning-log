# 子程序设计：参数传递与六个典型子程序

日期：2026-10-22　课程：汇编语言与微机接口

> 这一轮全在写子程序：CALL 怎么回去、参数怎么传、出口怎么约定。六个题目的骨架其实只有三四套。文末是易错点和自测。

## 一、为什么写成子程序

四个理由按重要性排：能复用（换个数据再 CALL 一次）、结构清楚（主程序只剩五六行，读的人不用看循环细节）、易改（只改子程序，所有调用点生效）、可单独调试（先喂已知输入验一个函数）。

代价是 CALL 与 RET 要压栈弹栈，多几条指令的时间。交互类程序完全无所谓；只有调上百万次、或者在最内层循环里，才值得考虑内联。

## 二、CALL 与 RET 到底做了什么

CALL 两件事：把 CALL 下一条指令的地址压进堆栈，再把 IP 改成子程序入口。RET 一件事：从栈里弹出那个地址，送回 IP。

举例，假设 `CALL UPPER` 在偏移 0012，指令长 3 字节：

| 时刻 | SP | 栈顶内容 | IP |
|---|---|---|---|
| CALL 之前 | FFFE | — | 0012 |
| CALL 执行后 | FFFC | 0015 | 子程序入口 |
| RET 执行后 | FFFE | — | 0015 |

所以 RET 不需要知道从哪儿回来，答案一直存在栈里。这也意味着：子程序内部如果压了东西，返回前必须弹干净，否则 RET 弹出的是数据不是地址，程序直接跳飞。

JMP 和 CALL 的区别就在这一条：JMP 不记路。

## 三、参数怎么传

| 方式 | 写法 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 寄存器 | 调用前把值放进约定寄存器 | 最快，不占内存，代码短 | 寄存器数量有限，会被改写 | 参数 ≤ 3 个 |
| 堆栈 | 调用前 PUSH，子程序内按 BP 取 | 参数个数不受限，支持递归 | 要维护 BP，返回后要清栈 | 参数多、递归 |
| 内存单元 | 双方约定一个变量放参数 | 最直观，参数多也行 | 多一次访存，耦合紧 | 教学示例、参数表 |
| 全局约定 | 如 SI、DI、CX 天然配合串操作 | 与指令集贴合 | 可读性差，容易踩到别的用途 | 串处理类 |

这六道题全用寄存器，因为参数都在三个以内。

## 四、入口出口约定怎么写

子程序开头必写两行注释，这是它和调用方的合同：

```
; 入口：SI 数组首地址，CX 元素个数
; 出口：AL 奇数个数
```

入口不写清楚，调用方就得去读代码猜；出口不写清楚，返回值在哪个寄存器里全靠运气。还要写明“哪些寄存器被破坏”，调用方才知道要不要先 PUSH 保护。

## 五、六个题目的骨架对比

| 题目 | 入口参数 | 出口 | 关键指令 |
|---|---|---|---|
| 小写转大写 | SI 串地址，CX 长度 | 原地改，无返回 | `SUB AL,'a'` + `CMP AL,25` + `ADD AL,'A'` |
| 指定位清零 | BX 地址，DH 类型，CL 位号 | 原地改，无返回 | `SHL` 造掩码 + `NOT` + `AND` |
| 长整数加减 | SI、DI 两数地址，BX 结果，CX 字数，DL 类型 | 结果写内存 | `CLC` + `ADC`／`SBB` + `LEA` 推进 |
| 字符串合并 | SI、DI 两串地址，BX 目标 | 结果串 | 两段循环，`'$'` 判尾 |
| 查找字符 | SI 串地址，AL 目标字符 | AX 位置，0FFFFH 表示没找到 | `CMP` + 计数 BX |
| 统计奇数 | SI 数组地址，CX 长度 | AL 个数 | `TEST AL,1` + `JZ` |

## 六、可复用的几个小手法

**判位用 TEST**：`TEST AL,1` 测最低位（奇偶），`TEST AL,80H` 测最高位（正负），不改原数据。

**判区间用先减后比**：小写字母先 `SUB AL,'a'`，结果落在 0 到 25 之间就是小写。一次无符号比较 `CMP AL,25` 替掉两次边界判断，数字和标点自动落到范围外。

**清位用掩码**：`MOV AL,1` → `SHL AL,CL` → `NOT AL` → `AND 原数`。目标位变 0，其余位保 1。

**跨字加减靠 CLC 加 ADC／SBB**：循环前 CLC，循环里带进位，指针用 LEA 推进（ADD 会毁掉 CF）。

**找位置用双指针**：SI 走数据，BX 数位置，两个一起加一，返回 BX 的值。

**判串尾用 '$'**：省掉长度参数，代价是字符串里不能出现 '$'。

## 七、易错点清单

1. `MOV AL,[SI]` 把 AL 里存的目标字符冲掉了，比较永远失败 → 改用 DL 装数据。
2. 计数器放在 AL，和取数据的 AL 冲突 → 换 AH 或 BL，最后再搬进 AL。
3. 忘了 `JCXZ`，长度为零时 LOOP 从 0 减成 FFFFH。
4. 多字运算用 `ADD SI,2` 推进指针，CF 被冲掉，进位链断。
5. 子程序里 PUSH 了 BX 却忘了 POP，RET 直接跳到垃圾地址。
6. 位置从 0 算还是从 1 算没写进注释，改代码的人踩坑。
7. 返回“未找到”用 0 表示，和“在下标 0 找到”撞车 → 用 0FFFFH。
8. 大小写转换两次边界比较颠倒顺序，把数字也减了 20H。
