# 汇编程序框架与转移指令（一次性串起来）

日期：2026-09-22　课程：汇编语言与微机接口（MASM + DOSBox）

> 下面的机器码都是本机用汇编器实测后反汇编出来的（8086 16 位），可以直接对着 DEBUG 的 `U` 命令核。

## 一、程序框架：三间房子

| 段 | 放什么 | 怎么起止 |
|---|---|---|
| **数据段** DATA | 变量、字符串、表格 | `DATA SEGMENT` … `DATA ENDS` |
| **堆栈段** STACK | 临时保存的东西（返回地址、现场） | `STACK SEGMENT STACK` … `STACK ENDS` |
| **代码段** CODE | 指令 | `CODE SEGMENT` … `CODE ENDS` |

骨架（可直接编译）：

```asm
DATA    SEGMENT
        MSG   DB  'Hello, MASM!$'
        NUM   DW  1234H
DATA    ENDS

STACK   SEGMENT STACK
        DW  100 DUP(?)
STACK   ENDS

CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA, SS:STACK
START:
        MOV  AX, DATA
        MOV  DS, AX                  ; 只有 DS 必须亲手装

        LEA  DX, MSG
        MOV  AH, 09H
        INT  21H

        MOV  AH, 4CH                 ; 体面退出（必须有）
        INT  21H
CODE    ENDS
END     START
```

四条必须记牢：
1. `SEGMENT` / `ENDS` 成对，段名首尾一致
2. `ASSUME` 只是**编译期**告诉汇编器，不会真的装段寄存器
3. **CS 由 `END START` 自动设、SS 由 `STACK SEGMENT STACK` 自动设，只有 DS 必须自己 `MOV AX,DATA / MOV DS,AX`**（且不能 `MOV DS,立即数`）
4. 结尾 `MOV AH,4CH; INT 21H` 收尾，否则程序顺着内存跑飞

## 二、转移指令怎么分类

**两把尺子**：
- 看目标位置 → **段内**（只改 IP）/ **段间**（改 CS:IP）
- 看地址来源 → **直接**（目标写在指令里）/ **间接**（目标从寄存器/内存取）

| | 段内 | 段间 |
|---|---|---|
| **直接** | `JMP 标号`、`CALL 标号` | `JMP FAR PTR 标号`、`JMP 段:偏移` |
| **间接** | `JMP BX`、`JMP WORD PTR [BX]` | `JMP DWORD PTR [BX]`、`CALL FAR PTR [BX]` |

## 三、短转移 / 近转移 / 远转移

| | 短 SHORT | 近 NEAR | 远 FAR |
|---|---|---|---|
| 范围 | 同段，±127 字节 | 同段，16 位位移（整段 64KB） | 跨段，任意位置 |
| 改谁 | 只改 IP | 只改 IP | **CS 和 IP 都改** |
| 机器码 | `EB` + 1B 位移（共 2B） | `E9` + 2B 位移（共 3B） | `EA` + 2B 偏移 + 2B 段（共 5B） |
| 写法 | `JMP SHORT 标号` | `JMP 标号`（默认） | `JMP FAR PTR 标号` |
| 条件转移能用？ | ✅ 只有它 | ❌ | ❌ |

## 四、DISP（位移量）

DISP = displacement，是"**加在某个基准上的偏移数字**"，本身不是地址。

| 场景 | 基准 | 结果 |
|---|---|---|
| 转移指令 | **下一条指令的地址**（IP 当时的值） | 目标 = IP + DISP |
| 存储器寻址 | 基址/变址寄存器（BX/BP/SI/DI） | EA = 寄存器 + DISP |

实测（看 DISP 在机器码里的位置）：
```
EB 01            jmp short → 往前 1 字节（从下一条算起）
8A 07            mov al,[bx]            ← 没有 DISP
8A 47 10         mov al,[bx+10H]        ← DISP = 10H（1 字节）
8A 81 34 12      mov al,[bx+di+1234H]   ← DISP = 1234H（2 字节，小端）
A0 34 12         mov al,[1234H]         ← 直接寻址＝只有 DISP，基准为零
```

**为什么用相对位移**：程序整段搬到内存别处，相对跳转依然正确（绝对地址写死就会错）。

## 五、操作码（机器码）速查

```
EB        JMP SHORT     1 字节位移
E9        JMP NEAR      2 字节位移
E8        CALL NEAR     2 字节位移（返回地址压栈）
EA        JMP FAR       4 字节（偏移 + 段）
9A        CALL FAR      4 字节（偏移 + 段）
70 ~ 7F   Jcc（条件转移）1 字节位移，只能短
FF /5     JMP FAR [BX]      （段间间接跳转）
FF /3     CALL FAR [BX]     （段间间接调用）
E3        JCXZ          （看 CX，不看标志位）
```

## 六、PTR：给汇编器"报大小"

PTR 是运算符（不是指令），**只影响汇编器怎么翻译，不产生机器码**。规则：

> 两个操作数里哪个自带大小就用哪个；都看不出来时必须写 PTR。

```
C6 07 05        mov byte [bx], 5      ← 写 1 字节
C7 07 05 00     mov word [bx], 5      ← 写 1 字（小端）
FE 07           inc byte [bx]
FF 07           inc word [bx]
8A 07           mov al,[bx]           ← 不用 PTR：AL 已说明大小
```
- 两个用法：**数据大小**（`BYTE/WORD/DWORD PTR`）、**转移距离**（`SHORT` / `NEAR PTR` / `FAR PTR`）
- 忘写会报 `operand must have size`（NASM：`operation size not specified`）

## 七、OFFSET 与 PTR 的区别（最易混）

| | `OFFSET VAR` | `PTR` |
|---|---|---|
| 是什么 | **取地址**运算符 | **大小/类型**说明符 |
| 结果 | 产生一个地址数值（立即数） | 不产生值，只改编码 |
| 例子 | `MOV BX, OFFSET VAR` | `MOV BYTE PTR [BX], 5` |

```
BB 00 01        mov bx, 0100h     ← 有 OFFSET：装的是「地址」
8B 1E 00 01     mov bx,[0100h]    ← 没 OFFSET：装的是「内容」
```
- `OFFSET` 只能用于**汇编期就能确定地址**的简单变量；带寄存器（`[BX+SI+10H]`）只能用 `LEA`
- **MASM 坑**：`MOV BX, VAR` 取**内容**（要地址必须写 OFFSET）；NASM 相反（`MOV BX, VAR` 取地址，取内容要写 `[VAR]`）

## 八、CALL / RET 与堆栈

```
CALL 标号： push 返回地址(IP)  →  IP ← 标号
RET      ： pop IP             →  回到调用点的下一条
```
- `RET` = **C3**（段内返回，只弹 IP）；`RETF` = **CB**（段间返回，弹 IP + CS）；`RET n` = `C2 n_lo n_hi`（弹回后再让 SP 加 n，丢掉调用者压的参数）
- 远调用的栈动作：**push CS → push IP**，`RETF` 则 **pop IP → pop CS**（顺序反过来才配对）
- **推论**：子程序里 push 了没 pop，`RET` 弹到的就不是返回地址 → 程序跑飞

## 九、条件转移

**本质**：看标志位决定跳不跳，**自己不改标志位** → 必须紧跟 `CMP`/`SUB`/`TEST`/`AND` 这类会改标志的指令。

| 依据 | 指令 | 机器码 |
|---|---|---|
| 相等/为零（ZF） | JE/JZ、JNE/JNZ | 74 / 75 |
| **无符号**比大小 | JA(77)、JAE(73)、JB(72)、JBE(76) | 看 CF/ZF |
| **有符号**比大小 | JG(7F)、JGE(7D)、JL(7C)、JLE(7E) | 看 SF/OF/ZF |
| 单标志位 | JC/JNC、JS/JNS、JO/JNO、JP/JNP | 72/73/78/79/70/71/7A/7B |
| 特例 | **JCXZ（E3）看不看标志，只看 CX** | — |

**别混用无符号和有符号**：
```asm
CMP AL, BL      ; AL=0FFH, BL=01H
JA  bigger      ; 无符号：255 > 1  → 跳
JL  smaller     ; 有符号：−1 < 1   → 也跳（方向相反）
```
两种机器码都合法，**汇编器不报错**，只在负数出现时才炸。

**口诀**：A/B（Above/Below）= 无符号；G/L（Greater/Less）= 有符号。
