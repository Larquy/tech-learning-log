# BCD 除法调整、多精度运算与 8088 总线

日期：2026-10-13　课程：汇编语言与微机接口（课堂纪要整理）

## 一、AAD（BCD 除法调整）的原理与局限

- **用在哪**：多位 BCD 码 ÷ 一位 BCD 码 ✓
- **调整时机**：**在运算之前** ✓ —— 与加减乘「运算**后**调整」正好相反 ✓
- **怎么调整**：把 AH 里的高位 BCD 码 **×10** 加上 AL 里的低位 BCD 码，
 即**十进制 → 二进制**，同时把 **AH 清零** ✓
- **与 AAM 的关系**：方向相反 ✓ —— AAM 是用乘法把二进制结果**调整成 BCD** ✓
- **局限**：只能对「除数为**单个** BCD 码」用 ✗ 除数位数一多就没法直接使用 ✓
 → 实际做除法时通常走**"字符串 → 二进制 → 运算 → 转回十进制"**的传统路子 ✓
- 要求：对该指令**只需了解原理和功能** ✓

## 二、多精度（长编码）运算的分块思路

- **64 位 = 4 个 16 位块**：从**最低 16 位**开始相加，进位用 **ADC** 往高位传 ✓
- **减法同理**：最低 16 位用 **SUB**，后面的高位块用 **SBB**（把借位考虑进去）✓
- 这套分块结构**本质就是一个循环** ✓ 与 BCD 加减"从低位到高位"的顺序一致 ✓
- **长编码乘法**：16 位块可看作 **$2^{16}$ 进制**的一个数位 →
 两个 64 位相乘 = **4 个 16 位块的交叉相乘再错位相加** ✓
- 因为 **$2^{16}$ 是 2 的整数次幂** → 二进制运算**不需要** BCD 那种调整 ✓
- 结论：**多精度数的长度只受内存容量限制，不受 CPU 字长限制** ✓
 （这就是大数运算、古典密码学里长编码处理的原理 ✓）
- 反向拓展：若要用二进制实现 **R 进制且 R 不是 2 的整数次幂** → 数位之间不存在整数倍关系 → **必须加调整步骤** ✓
- 要求：这部分**只作思路拓展** ✓ 理解「二进制长编码运算」与「BCD 运算」的**结构相似性**即可 ✓

## 三、8088 CPU：内部结构与引脚信号

**内部：BIU 与 EU 的分工**
- **BIU（总线接口单元）**：负责 CPU 与总线交互 —— **取指令、读写数据** ✓
 核心部件是**地址加法器**，把"段基址 + 偏移量"合成 **20 位物理地址** ✓
- **EU（执行单元）**：核心是 **ALU** ✓ 完成算术逻辑运算、产生标志位 ✓
 从**指令队列头部**取指令执行 ✓
- **两者并行工作 → 初级流水线** ✓：EU 执行当前指令的同时，BIU 可以预取下一条填进队列 ✓

**引脚：地址 / 数据的分时复用**
- **AD0–AD7**：**地址/数据复用** ✓ 靠时间片区分 —— **ALE 高电平时传地址**，**DEN 有效时传数据** ✓
- **A8–A15**：**纯地址输出** ✓ 有三态能力但**不复用** ✓
- **A16–A19 / S3–S6**：**地址/状态复用** ✓ ALE 无效时输出状态信号 ✓
- 数据总线**宏观双向**，具体时刻的**方向由 DT/R 控制**：高电平 = CPU 向外发 ✓ 低电平 = CPU 从外收 ✓

**控制信号与操作类型**
- **IO/M**：区分操作对象 —— **低电平访问内存**、**高电平访问 IO 端口** ✓
 与 **RD / WR** 组合 → 生成四种基本读写控制信号 ✓
- **DEN（数据允许）**：低电平有效，表示 AD0–AD7 正在传数据 ✓ **DT/R 配合 DEN** 决定数据流向 ✓
- **S0、S1、S2**：**最大模式**下用于区分总线周期类型 ✓
 **最小模式**下由 IO/M、RD/WR、DT/R 直接组合得出 ✓

**中断与 DMA 信号**
| 信号 | 方向/电平 | 作用 |
|---|---|---|
| **INTR** | 输入，高有效 | **可屏蔽**中断请求 ✓ 受 **IF** 控制（IF=0 时被屏蔽）✓ |
| **NMI** | 输入，高有效 | **不可屏蔽**中断 ✓ 用于硬件故障等致命错误 ✓ **不受 IF 影响** ✓ |
| **INTA** | 输出，低有效 | 中断响应 ✓ CPU 发出后，外部设备经数据总线送回**中断向量号** ✓ |
| **HOLD / HLDA** | 输入 / 输出 | **DMA 请求 / 响应** ✓ CPU 收到 HOLD 后让出总线，DMA 完成后撤销，CPU 收回控制权 ✓ |

**模式、时钟与复位**
- **MN/MX**：高 = **最小模式** ✓；低 = **最大模式**（部分引脚含义改变，需外接 **8288 总线控制器**）✓
- **RESET** 有效后：**CS=FFFFH、IP=0000H** → 从 **FFFF0H** 开始执行引导程序 ✓
- **CLK** 由 **8284 时钟发生器**提供 ✓ 主频 = 时钟周期的倒数（例：285 ns ≈ 3.5 MHz ✓）
- **VCC / GND** 接电源与地 ✓；**TEST** 引脚用于与协处理器 **8087** 同步检测 ✓

## 四、总线周期类型与状态信号

**S0–S6 的含义**
- **S5** 反映 **IF 标志**的当前状态 → 外部可由此知道 CPU 是否允许可屏蔽中断 ✓
- **S3、S4** 组合表示当前访问的段寄存器：**00=ES、01=SS、10=CS、11=DS** ✓
 讲者点评：S3/S4 **暴露了 CPU 内部段结构**，打破了封装性 ✗ 现代总线设计一般不再使用这类信号 ✓

**八种总线周期的状态组合**
| 总线周期 | 特征 |
|---|---|
| **系统级取指** | IO/M=0，CPU 按 CS:IP 自动读取下一条指令 ✓ |
| **指令级存储器读/写** | IO/M=0、S1=1 ✓ 由指令发起的数据访问 ✓ |
| **指令级 IO 读/写** | IO/M=1、S1=1 ✓ 对应 IN / OUT 指令 ✓ |
| **系统级 IO 读（中断响应）** | IO/M=1、S1=0 ✓ CPU 发 INTA 读取中断向量号 ✓ |
| **暂停周期** | 对应 HLT 指令，CPU 停止活动直到中断或复位 ✓ |
| **空闲状态 Ti** | 两个总线周期之间的过渡，总线上无操作 ✓ |

**READY 信号**
- 由**外部芯片（内存 / IO 接口）反馈给 CPU** ✓ 表示读写已完成 ✓
- **READY 无效 → CPU 在当前总线周期插入等待状态 Tw** ✓ 直到 READY 有效才结束 ✓
- **READY 属于控制总线** ✓ 是**外部对 CPU 的状态反馈**，不是 CPU 主动发出的控制信号 ✓

## 五、外部总线形成与辅助芯片

**地址总线：锁存与驱动**
- 20 位地址用 **3 片 8282 锁存器** ✓ **ALE 接 8282 的 STB 端** ✓ 在 ALE 有效时锁存 AD0–AD7、A16–A19 上的地址 ✓
- 8282 自带三态门：**不考虑 DMA 时 OE 接地**（三态门常通）→ 地址直接上总线 ✓
- **支持 DMA 时 OE 必须受控** ✓ —— CPU 让出总线时关掉三态门，避免冲突 ✓
- **74LS373** 可替代 8282 ✓ 功能相同、引脚排列不同 ✓

**数据总线：双向收发**
- 8 位数据总线用 **8286 双向三态缓冲器** ✓ **OE 接 DEN** ✓ DEN 有效则导通 ✓
- 方向端 **T 接 DT/R**：DT/R=1 → 数据 CPU→总线（A→B）✓；DT/R=0 → 总线→CPU（B→A）✓
- 8286 内部是**两组三态门构成的双向通路** ✓ OE 无效时两端高阻 → **总线隔离** ✓

**控制总线：译码与生成**
- 最小模式下，**IO/M + RD + WR 经译码** → 生成存储器读写、IO 读写四组控制信号 ✓
 分别接到内存芯片与 IO 接口的对应引脚 ✓（多数可一对一直连，少数需附加译码电路 ✓）
- **READY 经 8284 同步后**再送 CPU ✓ 8284 支持一级 / 二级同步方式选择 ✓

## 六、三态门与缓冲器的电路原理

- **三态门**：由使能端 T 控制 ✓ T 有效 → 信号单向通过 ✓；T 无效 → 输出端**高阻** ✓ 相当于物理断开 ✓
- **双向三态缓冲器** = 两个**方向相反**的三态门并联 ✓ 由方向控制端选择通路 ✓
 逻辑上**排除双向同时导通**的可能 ✓
- 缓冲器除方向控制外，还提供**信号隔离与驱动能力** ✓ 防止多设备同时驱动总线造成数据冲突 ✓
