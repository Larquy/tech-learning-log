# 8254 电子发声实验：方式 3 与查表演奏

2026-11-19　｜　计算机组成与汇编　补充实验（TDX-PITE）

一个音符一个频率，把对应频率的方波送到扬声器就出声。关键是 8254 的计数初值怎么算、怎么分两次写。

## 一、频率与初值

方式 3 输出方波，频率 f = 输入时钟 / 计数初值 N，所以 N = f_clk / f。

CLK0 接 1MHz，N = 1000000 / f。1000000 的十六进制是 0F4240H，超过 16 位，要用 DX:AX 拼。

## 二、控制字 36H 拆开看

36H 是 0011 0110。D7D6 选计数器 0，D5D4 是先低后高写 16 位，D3D2D1 是方式 3，D0 是二进制计数。

方式 3 的特别之处是自动重装，输出连续的方波，写完初值就不用管了，直到下次改写。

## 三、端口与接线

8254 挂在 IOY0 下，四个口：计数器 0 是 0600H，计数器 1 是 0602H，计数器 2 是 0604H，控制口是 0606H。

接线：CS 接 IOY0，A0 接 XA1，A1 接 XA2，D0 到 D7 接 XD0 到 XD7，RD 接 IOR#，WR 接 IOW#，CLK0 接 1MHz，OUT0 接电子发声单元的 SPK。GATE0 板上已上拉。

旧版 SOUND.ASM 用的是 IOY3 那组地址，在新装置上不适用。

## 四、查表演奏的结构

两张表一一对应，频率表 DW、时间表 DB，末尾放一个 0 当结束标志。

主循环四步：算初值、写初值、按节拍延时、指针后移。移到末尾的 0 就回表头重播。

写初值必须分两次，先低字节后高字节。DIV 之后 AX 是商，AH 就是商的高字节，别另找。

## 五、调音量的现实

方波幅度是 0 和 5V 两档，软件改不了。要小声只能动硬件：电子发声单元上若有音量电位器就拧小，没有就在 OUT0 到 SPK 之间串电阻，470 欧起试。

## 六、四个坑

CLK0 忘了接 1MHz，音高整体偏，最常见。
初值先写高字节后写低字节，频率全乱。
表尾忘了放 0，跑飞出去把后面的数据当频率。
没加堆栈段，链接虽然过，跑起来 CALL 有风险。
