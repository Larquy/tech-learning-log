# MOV 操作数合法性判定（做题经验：判断题怎么一眼看出错在哪）

日期：2026-10-19　课程：汇编语言与微机接口（MASM + DOSBox）

> 来源：课堂判断题，数据段是 `NUM1 DB 60`、`NUM2 EQU 50`、`NUM3 DB 20H`。这类题不考语义，只考**操作数能不能这么配**。下面是提炼出来的规则，换数字换变量名照样能用。

## 一、四条判定规则（按顺序查，命中就错）

| # | 规则 | 说明 |
|---|---|---|
| 1 | **长度必须一致** | `DB` 变量配 8 位操作数（AL、AH、8 位立即数）；`DW` 变量配 16 位（AX）；混合就是错 |
| 2 | **目的操作数不能是立即数或符号常量** | 立即数没有地址，写进去无处落地 |
| 3 | **两个操作数不能同时是存储器** | MOV 的源和目的不能都是 `[变量]`，必须经寄存器中转 |
| 4 | **汇编期表达式里不能出现寄存器** | 汇编器要在编译时算出常量，寄存器那时还没有值 |

## 二、本次 7 小问逐条对照

| 写法 | 判定 | 卡在哪 |
|---|---|---|
| `MOV NUM2, AL` | 错 | 规则 2：NUM2 是 `EQU` 符号常量，替换成 50，等于写 `MOV 50, AL` |
| `MOV AX, NUM3` | 错 | 规则 1：NUM3 是字节，AX 是 16 位 |
| `MOV NUM3, NUM1` | 错 | 规则 3：mem 到 mem |
| `MOV NUM1, NUM2` | 对 | NUM2 替换成 50，即立即数送字节单元；实测汇编成 `C6 06 0000 32` |
| `MOV BX, AX+NUM2` | 错 | 规则 4：地址表达式里不能有 AX；取地址要用 `LEA` |
| `MOV NUM1, AL and 0F0H` | 错 | 规则 4 的变体：`AND` 作运算符只能对常量求值，AL 运行时才有值 |
| `MOV AX, NUM3-NUM1` | 对 | 同段两个变量地址相减得常量（NUM1 占 1 字节、NUM3 紧跟，差值是 1）；实测汇编成 `B8 01 00` |

## 三、六个高频陷阱

**1. `EQU` 和 `DB` 不是一回事**
`NUM2 EQU 50` 只是给 50 起个名字，**不分配存储单元、没有地址**，编译时原样替换。所以它能当源操作数、能进常量表达式，**不能当目的操作数**。判断口诀：**这个符号有没有地址？有地址才能写。**

**2. mem 到 mem 必须拆两步**

```
MOV AL, NUM1     ; 先读进寄存器
MOV NUM3, AL     ; 再写出去
```

**3. 字节变量想送 AX，要自己扩展**

```
MOV AL, NUM3     ; 低 8 位
CBW              ; AL 符号扩展到 AX（无符号用 MOV AH, 0）
```

**4. 地址差的两种命运**
同段两个变量相减（`NUM3-NUM1`）得到常量，合法；但**变量加寄存器**（`AX+NUM2`）不是常量，汇编器算不出来。要算地址用 `LEA BX, NUM3`，要算值先指令算完再 MOV。

**5. `AND` / `OR` / `XOR` / `NOT` 双身份**
当运算符时只作用于常量：`MOV AL, 12H AND 0FH` 合法，汇编期就算成 `02H`；当指令时才作用于寄存器。混着写（`AL and 0F0H`）就是错。

**6. `PTR` 只改属性，不改长度错误**
`MOV BYTE PTR [BX], AL` 对；但 `MOV AX, BYTE PTR [BX]` 仍然错——PTR 只声明"按字节看待"，不会把 AX 变窄。

## 四、自测（3 题）

1. 接上题再写一条 `NUM4 DW 1234H`：`MOV AL, NUM4` 和 `MOV AX, NUM4` 哪个能过？为什么？
2. `NUM2 EQU 50` 的情况下，`ADD NUM2, 1` 为什么不行？要改哪一处才合法？
3. `MOV AX, NUM3-NUM1` 算出来是几？如果把 `NUM2 EQU 50` 改成 `NUM2 DB 50`，这条的结果变成几？

## 五、要点清单

1. 先查长度、再查"目的能不能写"、再查"是不是两个存储器"、最后查"表达式里有没有寄存器"
2. `EQU` 无地址、只替换，永远不能出现在目的操作数位置
3. mem 到 mem 一律经 AL/AX 中转
4. 字节变量送 AX 要先 `MOV AL` 再 `CBW`（或高字节清零）
5. 同段变量地址相减得常量，合法；寄存器不能进地址表达式
6. `AND` 当运算符只算常量，当指令才动寄存器
7. `PTR` 只改看待方式，不改操作数长度
