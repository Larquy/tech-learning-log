# 最小组态总线形成与 8284 时钟

日期：2026-10-16　课程：汇编语言与微机接口

> 本篇按课堂顺序整理：地址总线怎么锁、数据总线怎么缓冲、控制信号怎么译出，然后是 8284 的三路时钟与 READY 同步，最后是总线周期的三层时间体系和同步异步的混合机制。8284 的占空比、复位宽度、READY 为什么必须同步，另见 [20261020_8284时钟发生器三问](20261020_8284时钟发生器三问.md)。

## 一、地址总线：8282 锁存

8088 的 AD0 到 AD7、A16 到 A19 都是复用引脚，地址只在这几个引脚上停留很短一段时间（T1），之后就被数据或状态占了。

8282 就是干这件事的：ALE 为高期间，把地址打进锁存器，之后输出端一直维持这个地址，整个总线周期内都有效。

最小模式下 8282 的 OE 直接接地，意思是"永远允许输出"，它就成了透明的锁存器。要换成 74LS373 也能达到同样效果，两者功能等价，只是引脚定义和时序细节略有差别。

## 二、数据总线：8286 双向缓冲

8286 是双向三态缓冲器。A 端接 CPU 的 AD0 到 AD7，B 端接系统数据总线。

两根控制线分工：**DEN 是三态门的总开关**，决定缓冲器导不导通；**DT/R 决定方向**，是 CPU 往外发还是往里收。

为什么一定要有这一层：一是驱动能力，8088 的引脚带不动整条总线；二是隔离，DMA 控制器这类别的总线主控也要挂到总线上，靠三态断开才能保证同一时刻只有一个设备在驱动。

## 三、控制总线：译码生成

8088 本身只给出 IO/M、RD、WR 这几根，还不是外设能直接用的信号。

用组合逻辑（门电路）把它们译成四路：

| 信号 | 含义 | 生效条件 |
|---|---|---|
| IORD | I/O 读 | IO/M 高、RD 低 |
| IOWR | I/O 写 | IO/M 高、WR 低 |
| MEMRD | 存储器读 | IO/M 低、RD 低 |
| MEMWR | 存储器写 | IO/M 低、WR 低 |

这四路直接驱动外设芯片，是最小组态下控制总线的核心。它们和锁存器、缓冲器一起，构成"三总线"：地址总线、数据总线、控制总线。

## 四、8284 的三路输出

### 复位

机箱上的复位按钮是机械触点，按下和松开都会抖，直接送给 CPU 会变成一串毛刺。

8284 内部的施密特触发器先做整形，把抖动滤掉，输出一个干净的复位脉冲；脉冲的撤销还要和 CLK 上升沿对齐，避免 CPU 在时钟边沿附近退出复位造成亚稳态。

### 三路时钟

一颗晶振，出来三个频率，各管一摊：

**OSC** 是晶振原始频率，约 14.318MHz，专门供给显卡。这个数字和 NTSC 彩色副载波有关，是当年 PC 兼容性的历史产物。

**CLK** 是 OSC 三分频后的结果，约 4.77MHz，作为 8088 的主时钟。也可以改用外部时钟 EFI，用 F/C 引脚选择。

**PCLK** 是 CLK 再二分频，等于 OSC 六分频，供 8253 定时器使用，操作系统的时间片调度就以它为基准。

### 多片同步

系统里如果有多片 8284，把所有 CSYNC 引脚连起来并拉低，各芯片就会在同一时刻开始计数，消除相位偏差。单片使用时 CSYNC 接地即可。

要注意这个同步只管**启动时的初始相位**，不影响后续的频率稳定性。

## 五、READY 的同步

### 两级触发器的时序

外部给来的 RDY 是异步的，必须同步到 CLK 上再用。8284 内部用两个触发器：FF1 在 CLK 上升沿采样，FF2 在下降沿锁存。

所以 READY 什么时候能传到 CPU，取决于它在上升沿之前还是之后变高：上升沿前变高，下一个下降沿就能送出去；上升沿后才变高，得再等一个下降沿。

延迟范围大致是 1/3 个 CLK 到 4/3 个 CLK 之间。

### 最小脉宽

READY 的高电平必须维持足够宽，否则可能被当成毛刺滤掉。这个道理和键盘消抖一样：真实的按键是宽的，干扰是窄的，用宽度把两者分开。

### DMA 期间的屏蔽

DMA 接管总线时，AEN 变高，8284 内部逻辑把 READY 到 CPU 的通路掐断。

原因很清楚：这时候总线不归 CPU 管，READY 反映的是 DMA 和设备之间的握手，送给 CPU 会误导它以为自己的总线周期可以结束了。此时 READY 应该反馈给 DMA 控制器。

## 六、三层时间体系

| 层次 | 含义 | 组成 |
|---|---|---|
| 时钟周期 | 最小时间单位，CLK 的一个完整周期 | 一切操作的节拍基准 |
| 总线周期 | 完成一次总线操作 | 标准 4 个时钟周期，T1 到 T4 |
| 指令周期 | 执行一条指令的时间 | 若干个总线周期 |

有个细节值得注意：**中断响应、DMA 这类由硬件触发的总线周期不属于指令周期**。指令周期是按程序流算的，这些是被外部打断插进来的。

## 七、T1 到 T4，加上 Tw 和 Ti

四个状态顺序迁移，由 CLK 驱动：

T1 送地址 → T2 建立控制信号 → T3 检测 READY → T4 完成数据传送。

**Tw 是等待周期**：T3 结束时 READY 无效，就在 T3 和 T4 之间插一个或多个 Tw，直到 READY 有效。插几个由外设速度决定，所以总线周期长度是自适应的。

**Ti 是空闲周期**：相邻两个总线周期之间没有新请求，CPU 就停在 Ti；一旦有新请求，立刻从 Ti 进 T1。

## 八、同步与异步的混合

访问高速存储器时，不需要 READY 反馈，按固定时钟数走完就行，这是**同步**思路，效率高。

访问慢速外设时，靠 READY 握手决定插几个 Tw，这是**异步**思路，兼容性好。

8088 两者都用：T1 到 T4 的骨架是同步的，Tw 的插入靠 READY 异步反馈。这也解释了为什么同一个 CPU 既能配高速存储器又能配慢速接口卡。

## 九、两处建议核对的地方

**一是 F/C 引脚的电平方向**。笔记写"F/C 为高时选 EFI，为低时选内部 OSC"，但 8284 手册里 F/C 是高电平选晶振、低电平选 EFI，方向正好相反。这处影响的是外部时钟接入时怎么接，考到就亏了，建议跟老师或手册再对一遍。

**二是 READY 同步的级数是否可选**。笔记写 CSYNC 为高时是一级同步、为低时是二级同步；但 8284 的 CSYNC 引脚作用是**多片时钟同步**，不是 READY 的同步级数。READY 在 8284 内部固定走两级触发器。这一点也建议核对，别把两个功能记串。

## 十、易错点

- 8282 的 OE 接地不是"禁用"，而是"常通"，让它成为透明锁存器
- DEN 管通断、DT/R 管方向，两者分工别混
- CLK 是 OSC 三分频，PCLK 是 CLK 二分频（也就是 OSC 六分频），别把 PCLK 说成三分频
- 多片 8284 的同步只管初始相位，不管频率
- DMA 期间 READY 要被屏蔽，不是继续送 CPU
- 中断响应和 DMA 的总线周期不计入指令周期
- Tw 是动态插入的，数量不固定；Ti 是空闲等待，没有新请求才出现
