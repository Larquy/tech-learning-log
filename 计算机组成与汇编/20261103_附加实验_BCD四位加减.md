# 附加实验：四位十进制数的 BCD 加减

日期：2026-11-03　课程：汇编语言与微机接口

> 输入形如 `0728+0034=` 的算式，结果为四位十进制数，可能为负，用 BCD 实现，空行回车退出。记录结构与四个关键环节，以及调试中真正卡住的地方。

## 一、数据段布局

```
BUF    DB 11,0,11 DUP(?)   ; 0AH 缓冲区，可输 10 字符
NUM1   DW 0                ; 低字节存后两位，高字节存前两位
NUM2   DW 0
OPER   DB 0
RES    DB 3 DUP(0)         ; 五位结果，三字节
SIGN   DB '+'
```

输入 `0728+0034=` 后：`BUF+2..+5` 是前一个数，`BUF+6` 是运算符，`BUF+7..+10` 是后一个数，`BUF+11` 是回车。

## 二、ASCII 转压缩 BCD

两个字符拼成一个字节：第一个减 `'0'` 后左移四位，第二个减 `'0'` 后或进去。

```
MOV AL,[BUF+2]
SUB AL,'0'
MOV CL,4
SHL AL,CL
MOV BL,[BUF+3]
SUB BL,'0'
OR  AL,BL          ; 得到 07H
MOV BYTE PTR [NUM1+1],AL
```

一个字节装两位数字，所以四位十进制只占两个字节。低地址放后两位，是后面从低字节开始运算的方便。

## 三、加法链

```
    MOV CX,2
    CLC
L2: MOV AL,[SI]
    ADC AL,[DI]     ; 带上一轮的进位
    DAA             ; 必须紧跟，中间不能插指令
    MOV [BX],AL
    LEA SI,[SI+1]
    LEA DI,[DI+1]
    LEA BX,[BX+1]
    LOOP L2
    MOV AL,0
    ADC AL,0        ; 把最后的进位取出来
    MOV [RES+2],AL
```

两个要点：第二轮必须用 `ADC`，用 `ADD` 会丢掉低字节的进位，`9999+0001` 会算成 9900；指针自增用 `LEA` 或 `INC` 都行，它们不改 `CF`，而 `ADD SI,1` 会清掉进位标志。

## 四、减法

先比较哪个大，大的当被减数；交换过就把 `SIGN` 置成 `'-'`。运算用 `SBB` 配 `DAS`，链式规则跟加法一样。

## 五、输出与前导零

打印前先换行，否则结果会紧贴输入回显，看起来像多打了几位——这一条是实际调试中最容易误判的。

每位数字从字节里拆：高四位用 `SHR AL,CL`（CL=4）取，低四位用 `AND AL,0FH` 取，然后加 30H 变成字符。

前导零靠一个开关 `BX`：为 0 表示还没打过有效数字，遇到 0 就跳过；打出第一个非零后置 1，后面的 0 照打。

**BX 只能在开头置一次零。** 每处理一个字节就重置，会把中间位的 0 也吞掉，`7002` 显示成 `702`。

五位全是 0 时一个字都没打，最后判断 `BX` 仍为 0 就补一个 `'0'`。

## 六、验收数据

| 输入 | 输出 |
|---|---|
| `0728+0034=` | `+0762` |
| `0025-0621=` | `-0596` |
| `7002+0000=` | `+7002` |
| `9999+0001=` | `+10000` |
| `0000+0000=` | `+0` |

第二组验负数与符号，第三组验前导零，第四组验进位到第五位，第五组验全零。

## 七、踩过的坑

**IDE 编的是 tempfile.asm**。Masm for Windows 编译的是编辑器里的临时文件，不按 Ctrl+S，磁盘上的 `.asm` 一直是旧版。判断依据是 `.lst` 里的行号与磁盘文件对不上。

**`STACKS SEGMENT` 少了 `STACK` 关键字**，链接器不认作栈段，`SP` 未初始化，`PUSH` 会覆盖代码。

**`MOV [RES+2],CF` 不合法**，标志位不能当操作数，要 `MOV AL,0` / `ADC AL,0` / `MOV [RES+2],AL`。

**`LEA SI,SI+1` 这种写法**，MASM 能接受 `LEA SI,[SI+1]`，但更清楚的是 `INC SI`。

**压缩 BCD 只能用 DAA**。AAA 一个字节处理一位，`28H` 进去它只看低四位的 8，高位数字直接丢。

**`OPER` 忘了赋值**，`CMP OPER,'+'` 比较的是 0，永远走减法分支。解析完要 `MOV AL,[BUF+6]` / `MOV OPER,AL`。

**`SIGN` 每轮要重置**，减法会把它改成 `-`，下一轮加法就带着负号。
