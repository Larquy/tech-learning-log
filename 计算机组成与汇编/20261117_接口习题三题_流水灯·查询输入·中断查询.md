# 接口习题三题：键控流水灯、查询输入、中断查询

2026-11-17　｜　微机原理与接口技术

三题都出自第六章，考的是同一件事：CPU 怎么通过一个端口跟外部设备打交道。三题分别对应无条件传送、查询传送、中断传送三种方式。

## 一、6.4 键控流水灯（图 6-7，端口 6000H）

电路一头是三态缓冲器接八个开关，另一头是八位锁存器经反相驱动器接八盏灯，读写共用 6000H，靠 IOR 和 IOW 分开。

开关上拉接 +5V，按下接地，所以读回 0 表示按下。只按 K0 读回 FEH，只按 K1 是 FDH，只按 K7 是 7FH。其余组合都是"其他情况"，按要求不发光。

```asm
PORT    EQU   6000H
CODE    SEGMENT
        ASSUME CS:CODE
START:  MOV   DX, PORT

SCAN:   IN    AL, DX
        CMP   AL, 0FEH
        JE    UP
        CMP   AL, 0FDH
        JE    DOWN
        CMP   AL, 7FH
        JE    QUIT
        MOV   AL, 00H
        OUT   DX, AL
        JMP   SCAN

UP:     MOV   BL, 01H
UP1:    MOV   AL, BL
        OUT   DX, AL
        CALL  DELAY
        IN    AL, DX
        CMP   AL, 0FEH
        JNE   SCAN
        SHL   BL, 1
        JNZ   UP1
        JMP   UP

DOWN:   MOV   BL, 80H
DN1:    MOV   AL, BL
        OUT   DX, AL
        CALL  DELAY
        IN    AL, DX
        CMP   AL, 0FDH
        JNE   SCAN
        SHR   BL, 1
        JNZ   DN1
        JMP   DOWN

QUIT:   MOV   AL, 00H
        OUT   DX, AL
        MOV   AH, 4CH
        INT   21H

DELAY:  PUSH  CX
        MOV   CX, 0FFFFH
DL1:    LOOP  DL1
        POP   CX
        RET
CODE    ENDS
        END   START
```

三个要点：

图案放 BL，不放 CX。DELAY 要用 CX 数数，主程序再用 CX 数八步就会打架，所以灯走到哪一位用 BL 记，靠 `SHL` 左移自己归零来结束，不需要计数器。

`OUT DX,AL` 只能送 AL 或 AX，不能送 BL，所以每步先 `MOV AL,BL`。

反相驱动器的意思：写 1 输出 0，灯才亮。如果实测是写 0 才亮，在输出前加一句 `NOT AL`。

## 二、6.5 查询式输入 100 字节（图 6-9，数据口 8F40H，状态口 8F42H）

设备把数据锁进锁存器，同时把状态触发器置 1，表示"数据到了"。CPU 读状态口，D0 为 1 才去读数据口。读完数据，状态位自动清零，等下一个字节。

```asm
DATA    SEGMENT
INBUF   DB  100 DUP(?)
DATA    ENDS

CODE    SEGMENT
        ASSUME CS:CODE, DS:DATA
START:  MOV  AX, DATA
        MOV  DS, AX
        MOV  DI, OFFSET INBUF
        MOV  CX, 100
        MOV  DX, 8F42H

WAIT1:  IN   AL, DX
        TEST AL, 01H
        JZ   WAIT1
        MOV  DX, 8F40H
        IN   AL, DX
        MOV  [DI], AL
        INC  DI
        MOV  DX, 8F42H
        LOOP WAIT1

        MOV  AH, 4CH
        INT  21H
CODE    ENDS
        END  START
```

三个要点：

测一位用 `TEST AL,01H`，不用 `CMP AL,01H`。CMP 会把其他状态位一起比，别的位一变就误判。

读完数据必须把 DX 换回状态口，否则下一轮拿数据口当状态口读，把数据当状态判断。

循环一开始就把 DX 设成状态口，避免忘记。

## 三、6.8 中断查询（图 6-13、6-14，状态口 4000H）

八路中断请求进锁存器，同时经一个或门汇总成 INTR 送 CPU。CPU 响应后读 4000H，D0 到 D7 对应中断 0 到 7，1 表示有请求。

图 6-14 的排队顺序是从 D0 查到 D7，谁先查到响应谁。这套优先级不是硬件接出来的，是查询程序的先后顺序决定的，叫软件排队。

```asm
CODE    SEGMENT
        ASSUME CS:CODE
INTPROC PROC  FAR
        PUSH  AX
        PUSH  DX
        MOV   DX, 4000H
        IN    AL, DX

        TEST  AL, 01H
        JNZ   P0
        TEST  AL, 02H
        JNZ   P1
        TEST  AL, 04H
        JNZ   P2
        TEST  AL, 08H
        JNZ   P3
        TEST  AL, 10H
        JNZ   P4
        TEST  AL, 20H
        JNZ   P5
        TEST  AL, 40H
        JNZ   P6
        TEST  AL, 80H
        JNZ   P7
        JMP   DONE

P0:     CALL  INTP0
        JMP   DONE
P1:     CALL  INTP1
        JMP   DONE
P2:     CALL  INTP2
        JMP   DONE
P3:     CALL  INTP3
        JMP   DONE
P4:     CALL  INTP4
        JMP   DONE
P5:     CALL  INTP5
        JMP   DONE
P6:     CALL  INTP6
        JMP   DONE
P7:     CALL  INTP7

DONE:   POP   DX
        POP   AX
        IRET
INTPROC ENDP
CODE    ENDS
        END
```

三个要点：

八次 TEST 的掩码是 01、02、04、08、10、20、40、80，每次只看一位，所以几路同时请求也不会乱，先查到的先响应。

"1 表示有请求"，所以用 `JNZ` 跳，不是 `JZ`。

这段是中断服务程序，结尾用 `IRET` 不是 `RET`。如果老师要求在主程序里轮询，就把 PROC FAR 和 IRET 换掉，改成普通过程加 `RET`。

服务子程序里要清掉对应的请求位，否则退出后同一路会再报一次，程序在同一个服务程序里打转。

## 四、三题合起来看

端口地址超过 0FFH，一律先 `MOV DX, 端口`，`IN` 和 `OUT` 都用 DX 间接。

判断某一位，`TEST` 加 `JZ/JNZ`，不要用 CMP 整体比较。

三种传送方式的区别就在"要不要等"：无条件传送直接读，查询传送先看状态位，中断传送由设备主动打断。6.4 属于第一种，6.5 是第二种，6.8 是第三种。
