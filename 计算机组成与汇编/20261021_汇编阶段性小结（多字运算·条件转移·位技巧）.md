# 汇编阶段性小结：多字运算、条件转移与位技巧

日期：2026-10-21　课程：汇编语言与微机接口

> 这一轮集中做了十几道题，从单字节判断做到 128 位减法。题目各不相同，但拆开看只有五套骨架。这篇按骨架整理，不逐题抄代码。

## 一、这一轮练到的题型

| 题型 | 关键指令 | 一句话要点 |
|---|---|---|
| 字节数组统计奇偶、正负 | TEST、OR AL,AL、JS | 补码最低位判奇偶，最高位（SF）判正负 |
| 找第一个非空格字符 | CMP BYTE PTR、JNE | 位置基准要对，0FFH 表示没找到 |
| 求补码数组最大值 | CMP、JGE | 有符号比较，绝不能写 JAE |
| 统计 AL 中 1 的个数 | ROL、ADC AH,0 | 每次把最高位推进 CF，再用 ADC 累加 |
| 64 位无符号数除以 8 | CLC、RCR | 从高字往低字传位 |
| 128 位补码减法 | CLC、SBB | 从低字往高字传借位 |

两种方向的区别值得单独记：**右移（除）从高字做到低字，减法从低字做到高字**。前者是高位补进来的问题，后者是借位往上传的问题，方向搞反结果必错。

## 二、多字运算的统一骨架

只要跨字，就是三步：

```asm
    CLC              ; 第一步：清掉进位/借位，开局不带包袱
NEXT:
    MOV AX,[SI]
    SBB AX,[DI]      ; 或 RCR [SI],1，核心是带进位的指令
    MOV [BX],AX
    LEA SI,[SI+2]    ; 第二步：指针前进，但不能动标志位
    LEA DI,[DI+2]
    LOOP NEXT        ; 第三步：LOOP 本身不改标志
```

`CLC` 的作用是初始化：第一次运算没有来自更低位的进位，CF 必须先清零。

指针为什么用 `LEA` 不用 `ADD`，这是这一轮最容易踩的坑。`ADD SI,2` 会按结果重设 CF，而 CF 此刻正存着刚产生的进位或借位，一冲掉下一段就少算或多算一个 1。`LEA` 只算地址，一个标志都不碰；用两次 `INC` 也行，`INC` 同样不改 CF。

## 三、条件转移怎么选

判断的关键是数据本身有没有符号：

**无符号**用 `JA`、`JB`、`JAE`、`JBE`，它们看 CF。

**有符号**用 `JG`、`JL`、`JGE`、`JLE`，它们看 SF 和 OF 是否相等。

补码数组求最大值必须用 `JGE`。用 `JAE` 的话，-5 会被当成 FFFBH 这种接近最大的正数，负数越多结果越荒唐。

同一个 `CMP`，两条路都可能走成“小于”，但机制不同。比如 `CMP AL,BL` 中 AL=-5、BL=-3，结果 -2 使 SF=1、OF=0，`JGE` 因 SF≠OF 不跳；同时发生了借位 CF=1，`JAE` 也不跳。结论一致，原因完全是两回事，考题爱在这设坑。

## 四、位运算的三种固定用法

判奇偶：`TEST AL,1`，只看最低位，不改变操作数。

判正负：`OR AL,AL` 或 `TEST AL,AL`，值不变但按结果设标志，随后 `JS` 跳负数。这个写法比 `CMP AL,0` 短，也不影响累加器内容。

数 1 的个数：`ROL AL,1` 把最高位推进 CF，`ADC AH,0` 把它加到计数上，转 8 次正好把 8 位各过一遍。`ADC AH,0` 写成 `ADD AH,0` 就全归零了，这是这道题的陷阱。

负数不用特殊处理：8 位补码的最低位与原数奇偶一致，最高位直接表示符号，判奇偶和判正负都不需要先取绝对值。

## 五、循环控制

`LOOP` 是“先减一，再判是否为零”。所以 CX 初值为 0 时会减成 FFFFH，白白跑六万多次，还可能越界。

标准写法是循环前 `JCXZ` 挡一下。`JCXZ` 是条件转移里唯一不看标志位的一条，它直接查 CX 是不是 0。

遍历数组要两个东西一起动：一个指针（SI 或 BX）指向元素，一个计数器（CX）控制次数。少写指针递增，`LOOP` 每轮都在测同一个元素，结果就是“首元素是奇数就得到 9”这种假数据。

## 六、DEBUG 里的标志位

`R` 命令那串 `NV UP EI PL NZ NA PO NC` 就是 PSW，按 OF、DF、IF、SF、ZF、AF、PF、CF 的顺序排列。

NV/OV 对应 OF，PL/NG 对应 SF，NZ/ZR 对应 ZF，NC/CY 对应 CF，PO/PE 对应 PF，NA/AC 对应 AF。

判断一条指令的结果，套路是固定的：先看它改了哪些标志，再看那几位变成什么，最后才落到跳转走哪条路。

## 七、这一轮的易错点清单

写完程序先按这张表自查：

1. 指针递增写了没有，位置对不对（在分支汇合处只写一次）
2. 多字运算循环前 CLC 了没有
3. 指针推进用的是 LEA/INC 还是 ADD（后者会毁掉 CF）
4. 有符号比较用了 JGE 还是一不小心写成 JAE
5. `ADC AH,0` 有没有手滑写成 `ADD AH,0`
6. 循环前有没有 JCXZ 防 0
7. 字节还是字，`BYTE PTR`/`WORD PTR` 标了没有
8. 偏移计算有没有把元素个数和字节数搞混（`$ - ARY1` 对 DB 是字节数，对 DW 要除 2）
