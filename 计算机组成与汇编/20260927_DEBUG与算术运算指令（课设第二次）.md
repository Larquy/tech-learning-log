# DEBUG 基本命令与算术运算指令（课程设计 · 第二次实验）

## 一、实验目的

- 熟练掌握 **DEBUG 基本调试命令**，能用 DEBUG 编写、调试汇编程序片段。
- 在理解**算术运算指令**的基础上，对指定程序片段调试并记录。

## 二、实验报告要求（3 条）

1. 说明所学 DEBUG 基本命令的使用方法。
2. 分析指定源程序：**执行到指定位置后，寄存器、标志位的取值**，解释指令执行原理，并记录必要的寄存器/标志位状态。
3. **分析程序片段的功能** —— 必须在报告里说明。

## 三、本次实验指定的程序片段

```asm
        MOV  WORD PTR [0100H], 5564H
        MOV  WORD PTR [0102H], 0C279H
        MOV  AX, [0100H]
        PUSH AX
        ADD  AL, [0102H]        ; 说明标志位是如何确定的
        ADC  AH, [0103H]        ; 说明指令执行原理，包括标志位
        MOV  [0104H], AX
        POP  AX
        SUB  AL, [0102H]        ; 说明标志位是如何确定的
        SBB  AH, [0103H]        ; 说明指令执行原理，包括标志位
        MOV  [0106H], AX
        ; 最后说明程序执行完毕后，字单元 [0104H]、[0106H] 的内容
```

## 四、参考分析（自己核过，用来对照报告）

**内存初值**（小端）：`[0100H]=5564H` → 0100H=64H、0101H=55H；`[0102H]=0C279H` → 0102H=79H、0103H=C2H

| # | 指令 | 执行结果 | 标志位 |
|---|---|---|---|
| 1 | `MOV WORD PTR [0100H],5564H` | 0100H=64H、0101H=55H | **MOV 不改任何标志位** |
| 2 | `MOV WORD PTR [0102H],0C279H` | 0102H=79H、0103H=C2H | 不变 |
| 3 | `MOV AX,[0100H]` | AX=**5564H**（AL=64H，AH=55H）| 不变 |
| 4 | `PUSH AX` | AX 压栈（SP−2），保存初值 | 不变 |
| 5 | `ADD AL,[0102H]` | AL=64H+79H=**DDH** | CF=0 AF=0 SF=1 ZF=0 **OF=1** PF=1 |
| 6 | `ADC AH,[0103H]` | AH=55H+C2H+0=**17H**，CF=1 | CF=1 AF=0 SF=0 ZF=0 OF=0 PF=0 |
| 7 | `MOV [0104H],AX` | **[0104H]=17DDH** | 不变 |
| 8 | `POP AX` | AX 还原为 **5564H** | 不变 |
| 9 | `SUB AL,[0102H]` | AL=64H−79H=**EBH** | **CF=1 AF=1** SF=1 ZF=0 OF=0 PF=1 |
| 10 | `SBB AH,[0103H]` | AH=55H−C2H−1=**92H**，CF=1 | CF=1 AF=0 SF=1 ZF=0 **OF=1** PF=0 |
| 11 | `MOV [0106H],AX` | **[0106H]=92EBH** | 不变 |

**标志位是怎么"算出来"的**（老师要你说明这个）：
- **CF**：加法看**有没有进位出第 15/7 位**（64+79 无进位→0；55+C2+0 有→1）；减法看**有没有借位**（64−79 有→1）
- **AF**：看**低 4 位有没有进位/借位到第 4 位**（4+9=D 无→0；4−9 有借位→1）
- **SF**：结果最高位（DDH/EBH/92H 最高位 1 → SF=1；17H → 0）
- **ZF**：结果是不是 0（这几条都不是 → 0）
- **OF**：**同号相加/异号相减却符号错了**才置 1 ✓（⑤ 正+正=负 → 1；⑩ 正−负=正溢出 → 1）
- **PF**：结果**低 8 位中 1 的个数是偶数** → 1（DDH 6 个 1 → 1；17H 3 个 → 0）

## 五、程序功能（报告第 3 条要写的）

这段程序演示的是**用字节运算实现字运算**，也就是**多字节（多精度）加减法的基本套路**：

- **加法**：把 [0100H] 处的字（5564H）与 [0102H] 处的字（0C279H）相加
 → 数学结果 = **117DDH**；程序保留低 16 位存 [0104H]（**CF=1 就是"进到第 17 位"的那一位** ✓）
- **减法**：两数相减 → 5564H − 0C279H = **92EBH**，存 [0106H]（**CF=1 表示有借位** ✓）
- **手段**：低字节用 `ADD`/`SUB`，高字节用 `ADC`/`SBB` **把低位产生的进位/借位接过来** ✓
- **PUSH AX / POP AX 的作用**：加法和减法都要拿 AX 当被操作数 → 先保存初值，减完再还原 ✓
- **结束时 AX = 92EBH**（最后一步 `MOV [0106H],AX` 并不改变 AX ✓）

## 六、DEBUG 命令（本次新学 G / D / E）

| 命令 | 功能 | 用法 |
|---|---|---|
| **G** | **连续执行**，执行到指定断点前一条为止暂停并显示 CPU 现场 | `-g`（直接跑完）／`-g XXXX:XXXX` |
| **D** | 查看指定内存区域内容 | `-d`（从默认数据段开始/接着上次）／`-d XXXX:XXXX` |
| **E** | 修改指定内存单元内容 | `-e XXXX:XXXX` |
| （复习）r / a / u / t | 看改寄存器 / 汇编输入 / 反汇编 / 单步 | 见第一次实验整理 |

⚠️ **G 命令的断点必须是"某条指令的首字节地址"** ✗ 给到指令中间会出问题 ✓

## 七、注意事项（老师特别强调）

1. **先用 `r` 命令改 `DS`、`SS`**，让它和 `CS` 指向**不同位置** ✓
2. 建议：**DS 原始段基值 + 0100H**、**SS 原始段基值 + 0200H** ✓
3. 目的：**避免数据段/堆栈段的操作覆盖代码段里已录入的指令**，影响重复调试 ✓
 （因为这段程序往 [0100H]、[0104H]、[0106H] 写数据 ✗ 不分开就会把自己的指令冲掉 ✓）

## 八、易错点

1. `MOV WORD PTR [0100H],5564H` **必须写 `WORD PTR`** ✗（否则类型不明确 ✓）
2. **`ADD AL,[0102H]` 取的是"字节"** ✓，`ADC AH,[0103H]` 取的是**下一个字节** ✓ —— 高低字节别取反 ✗
3. 小端存储：写 `5564H` 时 **64H 在低地址（0100H）** ✓
4. **AF 和 PF 最容易被忽略** ✗ 报告里要写全 6 个标志位（CF/PF/AF/ZF/SF/OF ✓）
5. `ADC`/`SBB` 的 CF 来自**上一条指令**，不是自己算出来的 ✗
