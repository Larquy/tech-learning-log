## 一、名词解释

1. **CF 标志**：进位借位标志。加减法指令在最高位产生进位或借位时置 1，否则置 0；部分逻辑运算指令会把 CF 强行清零。
2. **逻辑地址**：CPU 内部表示存储单元地址的形式，由段基值和偏移量两部分组成，各 16 位。
3. **变址寻址**：一种存储器寻址方式，偏移量由变址分量与位移量分量相加得到，位移量由指令直接给出，变址分量放在 SI 或 DI 中。
4. **寄存器间接寻址**：一种存储器寻址方式，偏移量由地址指针寄存器间接提供，指针可以是 BX、BP、SI、DI 之一。
5. **SF 标志**：符号标志。执行算术或逻辑运算后，SF 与结果的最高位保持一致；把操作数当作补码看时，SF 就是结果的符号位。

## 二、计算题

**1. 8 位补码 11001111，求真值。**

符号位为 1，是负数。取反得 00110000，加 1 得 00110001，即十进制 49，所以真值是 -00110001B，也就是 -49。

【修正】原答案取反后算作 00110000、加 1 仍写 00110000，最后给 -00110000，比正确值少 1，实际是 -48。补码转换的最后一步别忘了加 1。

**2. 8 位二进制真值 -01011100，求补码。**

负数取反加一。绝对值 01011100 取反得 10100011，加 1 得 10100100，所以补码是 10100100B。

**3. 设 (AL)=00001011，(BL)=11100011，执行 SUB AL,BL 后 OF 等于多少。**

00001011 - 11100011 = 00101000，即 28H。被减数最高位为 0，是正数；减数最高位为 1，是负数。异号相减等价于同号相加，两个正数相加结果最高位仍为 0，符号正确，没有溢出，所以 OF=0。

**4. 设 (AL)=01100110，(BL)=11111101，执行 SUB AL,BL 后 CF 等于多少。**

01100110 - 11111101 = 01101001，即 69H。判断 CF 要把两个数当无符号数看：66H 小于 FDH，减法产生借位，所以 CF=1。

**5. 设 (BX)=01FDH，(SI)=02A4H，对指令 ADD 0100H[BX][SI], AL，写出目的操作数的寻址方式并计算偏移量。**

目的操作数是带位移量的基址变址寻址（教材常简写为基址变址寻址）。

EA = BX + SI + 0100H = 01FDH + 02A4H + 0100H = 05A1H。

## 三、排错题

1. **PUSH 2360H** 错误。8086 的 PUSH 只接受寄存器或存储器操作数，不能直接压入立即数。
2. **SBB AX** 错误。SBB 是双操作数指令，这里少一个源操作数。
3. **DEC CL, DL** 错误。DEC 是单操作数指令，这里多给了一个操作数。
4. **ADC BL, CX** 错误。长度不匹配，BL 是 8 位，CX 是 16 位。
5. **MOV DS, 0297H** 错误。段寄存器不能用立即数直接赋值，必须经通用寄存器中转，例如先 MOV AX,0297H 再 MOV DS,AX。

## 四、程序分析题

**1.**

```
MOV AL，92H
MOV BL，3BH
ADD AL，BL
```

AL = 0CDH，BL = 3BH，CF = 0，OF = 0，SF = 1。

92H 与 3BH 相加得 CDH。最高位没有进位，CF=0；两个操作数一个负一个正，结果在 8 位补码范围内，没有溢出，OF=0；结果的最高位是 1，SF=1。

**2.**

```
MOV AL，6EH
MOV BL，9FH
SUB AL，BL
```

AL = 0CFH，AF = 1，CF = 1，OF = 1，PF = 1。

6EH 减 9FH 借位得 CFH。低四位 E 减 F 产生借位，AF=1；无符号比较 6EH 小于 9FH，CF=1；按补码看是正数减负数，结果超出范围，OF=1；CFH 的二进制是 11001111，六个 1，偶数个，PF=1。

**3.**

```
MOV AL，99H
MOV CL，02H
SHL AL，CL
```

AL = 64H，PF = 0，CF = 0，SF = 0。

99H 左移两位得 264H，取低 8 位即 64H。最后一次移出的是 32H 的最高位，为 0，所以 CF=0；64H 是 01100100，三个 1，奇数个，PF=0；最高位为 0，SF=0。

**4.**

```
MOV AL，78H
MOV BL，64H
AND AL，BL
SBB AL，BL
```

AL = 0FCH，CF = 1，OF = 0。

AND 之后 AL 变为 60H，同时 CF 被清零。再用 SBB 减 64H，60H 减 64H 借位得 FCH，CF=1；按补码看 96 减 100 得 -4，没有溢出，OF=0。

**5.** 设 (DS)=0200H，字节单元 (02028H)=2AH，(02029H)=0A2H。

```
MOV SI，0029H
MOV DI，SI
MOV AL，[SI]
DEC DI
SUB AL，DS:[DI]
```

AL = 78H，CF = 0，OF = 1，SF = 0。

[SI] 取到 02029H 处的 A2H。DI 减一后指向 02028H，取到 2AH。A2H 减 2AH 得 78H。无符号比较 A2H 大于 2AH，不借位，CF=0；按补码看是 -94 减 42 得 -136，小于 -128，溢出，OF=1；结果 78H 最高位为 0，SF=0。

## 五、程序设计题

**1. 检测 AL 最低位与最高位，相等则 BL 置 1，否则置 0。**

```
MOV BL, AL
AND BL, 01H        ; BL 只留最低位
MOV CL, AL
SHR CL, 7          ; CL 只留最高位
XOR BL, CL         ; 两位相同得 0，不同得 1
XOR BL, 01H        ; 取反，相同得 1，不同得 0
```

【修正】原答案用 ROL 加两次 AND 加两次 XOR，我按 AL=00000001B 走了一遍，最后 BL 是 03H，既不是 1 也不是 0，实现不了题目的要求。上面这版才是对的：先把最高位和最低位各自抽出来，异或判断是否相同，再取反。

**2. 不用乘除指令，实现 (AX × 9 − 12) 除以 8，AX 按补码理解。**

```
MOV BX, AX
MOV CL, 3
SHL AX, CL         ; AX 乘 8
ADD AX, BX         ; 再加一次原值，得 AX 乘 9
SUB AX, 12         ; 减 12
MOV CL, 3
SAR AX, CL         ; 算术右移 3 位，相当于除 8
```

【修正】原答案最后一步用的是 SHR，逻辑右移。AX 是补码，负数右移时 SHR 会在高位补 0，符号位被冲掉，结果完全错。这里必须用 SAR，右移时复制符号位。

## 校对说明

1. 计算题第 1 小题：原答案真值写成 -00110000，正确是 -49 即 -00110001B（加一那步漏了）。
2. 程序设计第 1 小题：原答案的指令序列跑不出题目要的 0 或 1，已换成按位抽取加异或的写法。
3. 程序设计第 2 小题：原答案用 SHR 处理补码，负数会算错，已改为 SAR。
4. 原卷排错题标题写 4 小题，实际列了 5 条，按 5 条整理。

## 这份卷子考什么

前四题 80 分全在指令、标志位、寻址这一块：名词解释只考标志位和寻址方式，计算题是补码转换加 CF、OF 判断加 EA 计算，排错题是五类常见指令错误，程序分析是逐条手算寄存器和标志位。最后 15 分才是设计题。

复习优先级：五个标志位的置位规则最先，然后是无符号溢出看 CF、有符号溢出看 OF 这个区分，再是五类排错模板，最后练手写位运算。
