# 从零开始：MNIST 作业的地基（张量与形状）

2026-11-17　｜　人工智能概论

作业是 CNN 识别手写数字，截止 12 月 6 日。这是从零补起的第一讲内容，先把张量和数据形状弄明白，再谈网络。

## 一、张量是装数字的方盒子

零维是一个数，`3`。

一维是一行，`[3, 5, 1]`。

二维是一张表。一张灰度图就是 28 行 28 列的表格，每格是那个像素的亮度。

三维是几张表叠起来。彩色图是三张表，红绿蓝各一张，所以写 28×28×3。

四维是一次看一批。128 张灰度图叠成 128×1×28×28，第一层是样本数。

「形状」这个词说的就是每层有多少格。形状对不上，后面的矩阵乘法和卷积都做不了。

## 二、MNIST 是什么

七万张 28×28 的手写数字灰度图，内容是 0 到 9。九十年代 LeCun 那批人整理，图源是美国人口普查表和高中生填的表格，统一成同样大小。名字里的 M 是 modified，指在原始 NIST 上重新整理过。

六万张带标签用来训练，一万张不给答案用来测试。深度学习的入门第一课基本都从它开始，图小、干净、跑得快。

这次作业用的版本是 Kaggle 重分过的：42000 张训练、28000 张测试，格式不是图片文件，而是一行 784 个数字，一行就是一张图。

## 三、784 是怎么来的

28 乘 28 等于 784。把表格从第一行开始，一行接一行抽出来，接成一条长龙，就是 784 个数，每个在 0 到 255 之间。

`reshape` 不是改数字，是把同一条长龙按原样折回表格。折错方向也能折回来，信息一个不丢。

真实数据的形状是 `[42000, 784]`，第一层 42000 个样本，第二层每样本 784 个特征。要变成卷积能吃的四维，写 `reshape(-1, 1, 28, 28)`，那个 `-1` 表示这一维让程序自己算。

```python
import torch
a = torch.zeros(28, 28)
b = a.reshape(784)
print(a.shape)   # torch.Size([28, 28])
print(b.shape)   # torch.Size([784])
```

括号里几个数就是几维，每个数是那一层有多少格。

## 四、torch 提供什么

张量：能一次对几万个数做同样运算的多维数组，比 Python 列表好用。

自动求导：写模型时不用自己推梯度公式，它把每步运算记下来，`loss.backward()` 一句就全算好。这是它和 numpy 最大的区别。

nn 积木：卷积层、全连接层、池化层、激活函数都是现成的。

优化器：梯度下降的各种变体，把参数交给它，它按梯度改数。

还能把计算搬到显卡上。本机装的是 CPU 版，跑 MNIST 够用，一轮几分钟。

数据读取交给 torchvision，配套的另一个库，负责下载和预处理数据集。
