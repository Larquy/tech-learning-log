# 注意力机制、预训练范式与位置编码演进

日期：2026-10-20　课程：人工智能概论

> 本篇按课堂顺序整理：三种注意力机制 → 残差连接 → 自回归生成与解码策略 → 评价体系 → 预训练范式 → GPT 系列 → BERT 与 T5 → 位置编码演进 → 当前应用现状。文末附对比表、易错点和自测。

## 一、三种注意力机制

### 自注意力（Self-Attention）

名字里的 self 说的是 **Q、K、V 三个向量都由同一个输入序列生成**。流程是：用 Q 和 K 算出词与词之间的关联度，归一化成注意力权重，再拿权重去加权求和 V，得到每个位置的输出表征。

一句话概括分工：Q 是"我要找什么"，K 是"我有什么标签"，V 是"我实际提供什么内容"。

### 掩码自注意力（Masked Self-Attention）

只出现在 Decoder 里。目的是**防止训练时看到未来的 Token**：预测第 $t$ 个词时，只能依赖第 1 到 $t-1$ 个词。

做法是在 Q 与 K 算出的关联度矩阵上叠加一个掩码矩阵，把当前位置之后（含自己之外未来）的分数置成负无穷，softmax 之后这些位置的权重就成了 0。

这条机制和 Decoder 的自回归生成方式是一一对应的：$t$ 时刻根据 $1$ 到 $t-1$ 的上下文预测 $Y_t$，生成完再把 $Y_t$ 拼回上下文去预测 $Y_{t+1}$。

### 交叉注意力（Cross-Attention）

用在 Encoder-Decoder 结构的 Decoder 里。区别只在 Q、K、V 的来源：

- **Q 来自 Decoder**，是掩码自注意力之后的输出，代表当前解码状态"想知道什么"
- **K 和 V 来自 Encoder 的输出**，承载源文本的语义

每解码一个词，Q 都在变，所以模型对源句的关注点也在移动，这就是机器翻译里目标词和源词动态对齐的机制。

### 三者对比

| | Q 来源 | K 来源 | V 来源 | 额外组件 |
|---|---|---|---|---|
| 自注意力 | 输入序列 | 输入序列 | 输入序列 | 无 |
| 掩码自注意力 | 输入序列 | 输入序列 | 输入序列 | 掩码矩阵 |
| 交叉注意力 | Decoder | Encoder | Encoder | 无（但 KV 跨来源） |

基础计算公式完全一致，都是 softmax 打分再加权求和。所谓的"区别"只有两处：**加不加掩码**，**KV 从哪来**。

## 二、残差连接

做法简单：子层的输入 $x$ 和子层的输出 $F(x)$ 相加，得到 $x+F(x)$。

价值有两个。

第一是**缓解梯度消失**。反向传播时

$$\frac{\partial (x+F(x))}{\partial x}=1+F'(x)$$

那个恒等项 1 保证梯度里始终有一条直通路径，不管 $F'$ 被连乘衰减到什么程度，梯度都不会归零。深层网络能训起来，靠的就是这一项。

第二是**缓解退化**。层数加深以后，模型能力反而下降，不是因为过拟合，而是优化困难。有了跳跃连接，多余的网络层至少可以学成恒等映射，最坏情况不会比浅层更差。

## 三、自回归生成与解码策略

### 生成流程

给定初始词序列，模型输出**词表上每个 Token 的概率分布**，按解码策略选出一个词，追加到上下文末尾，再喂回去预测下一个，直到遇到结束符 EOS 或者达到最大生成长度。

注意每一步模型给的都是概率分布，不是某个确定的词。**具体选哪个词是解码策略决定的**，这一层经常被忽略。

### 贪心搜索与随机采样

**贪心搜索**每步取概率最高的那个 Token。文本通顺、稳定，但容易重复、缺少变化。

**随机采样**从概率靠前的一批 Token 里随机挑，多样性好，代价是可能跑偏、前后不连贯。

实际系统里通常给一个温度参数或 top-k、top-p 来调这两者的平衡，温度低偏贪心，温度高偏随机。

## 四、评价体系

**外部评价**：看模型在具体下游任务上的表现，比如分类准不准、翻译好不好。贴近实际用途，但要针对每个任务单独准备数据。

**内部评价**：用困惑度（Perplexity）。它衡量模型对真实文本的预测不确定性：概率分布越集中、和真实文本越吻合，困惑度越低。

要提醒的是，**困惑度低不等于模型说的对**。它只反映"预测下一个词时有多确定"，一个把错误事实说得很流利的模型，困惑度可以很低。所以评估语言模型通常要内外部结合，再加生成文本与参考答案的相似度之类的指标。

## 五、预训练范式

两阶段：

**预训练**：在大规模无标注通用语料上跑自监督任务，学语言的共性规律和通用特征。

**微调**：在特定任务的少量标注数据上适配，只更新少量参数，或者加少量新参数。

它解决的三个老问题：

| 传统 NLP 的痛点 | 预训练怎么解 |
|---|---|
| 标注数据稀缺、成本高 | 无标注语料便宜，预训练学到通用知识后，下游只需少量标注 |
| 模型从零学语法和上下文关系 | 语言常识和结构理解已经在预训练里获得，不必重复学 |
| 每个任务独立训练，知识不共享 | 所有任务共享同一个基座模型，知识跨任务复用 |

## 六、GPT 系列的演进

| | 架构 | 训练目标 | 下游任务 | 关键贡献 |
|---|---|---|---|---|
| GPT-1 | Decoder-only，去掉交叉注意力 | 自回归预测下一个词，自监督 | 需要微调，加特殊 Token 适配 | 立起"生成式预训练"这条路 |
| GPT-2 | 同上 | 同上 | Zero-shot，只加任务描述 Prompt | 验证"数据够多、模型够大就不用微调" |
| GPT-3 | 同上 | 同上 | In-context learning，one-shot/few-shot | 大规模实证 Scaling Law，出现涌现 |

几个点值得单独记：

- Decoder-only 结构里**没有交叉注意力**，只有掩码自注意力，因为不存在"源文本"这一侧。
- 自监督的意思是文本自己既是输入又是标签：拿前 $n$ 个词当输入，第 $n+1$ 个词当标签。
- 上下文学习不更新任何参数，全靠 Prompt 里的示例把任务"说"给模型听，这是它和微调的本质区别。
- Scaling Law 说的是能力随规模呈幂次增长，规模跨过某个门槛后会出现小模型完全没有的能力。

## 七、BERT：Encoder-only 的双向理解模型

架构上只有 Encoder，每个 Token 能同时看前后文，这是"双向"的含义。代价是它没法做自回归生成。

两个预训练任务：

**MLM（掩码语言建模）**：随机遮住 15% 的 Token 让模型猜。遮挡方式有三种：换成 `[MASK]`、换成随机 Token、保持不变。三种混着来，是为了让模型别只盯着 `[MASK]` 这一个符号。

**NSP（下一句预测）**：输入两个句子，判断是不是连续上下文。正负样本各占一半，负样本是从语料里随便拼的。

位置编码用的是**可学习的绝对位置向量**，另外加了**段落编码**来区分句子属于 A 还是 B。

擅长理解类任务，比如分类、抽取；不擅长生成。

## 八、T5：把一切变成文本生成

架构是完整的 Encoder-Decoder：Encoder 建模输入语义，Decoder 自回归生成输出。

预训练任务是**连续片段掩码**：也是遮 15%，但遮的是连续的文本片段，不是一个个孤立的 Token。BERT 要求模型靠局部上下文填空，T5 要求它生成一整段，本质是生成任务。

微调上用**文本到文本**的统一框架：所有任务都写成"输入文本 → 输出文本"，连分类也不例外，标签直接变成字符串输出。输入里再塞一句任务描述，理解类和生成类就统一在同一套接口下了。

位置编码用**相对位置偏置**，而且做了分桶：近距离（比如 0 到 7）每个距离单独一桶，远距离（8 到 11、12 到 15）合并成更粗的桶，距离越远共用范围越大。

这一点很容易记混：**相对位置偏置是加在注意力得分上的，不是加在词向量上**。加在词向量上的是绝对位置编码。

## 九、位置编码的演进脉络

| 阶段 | 代表 | 形式 | 加在哪 |
|---|---|---|---|
| 原始 Transformer | 正余弦函数 | 按公式算出固定向量 | 与词向量相加 |
| GPT / BERT | 可学习绝对位置向量 | 维度同词向量，训练得到 | 与词向量相加 |
| T5 | 相对位置偏置 | 离散距离分桶 | 加在注意力得分上 |
| 主流大模型 | 旋转位置编码 RoPE | 对 Q、K 做旋转 | 作用于 Q、K 的生成过程 |

演进的方向很清楚：从"固定公式"到"学出来"，从"绝对位置"到"相对距离"，从"加在输入端"到"作用在注意力内部"。RoPE 之所以成为主流，是因为它把位置信息直接转进 Q 和 K 的相对夹角里，外推性更好。

## 十、当前的应用现状

理解类任务，比如谣言分类、关系抽取，**BERT 仍然是主力基座**。常见做法是用 BERT 生成初始词向量，再接一个下游任务网络继续训练。

生成类任务，优先选 GPT 系列或者 T5 这类 Decoder-based / Encoder-Decoder 架构。

选型的判据不是"哪个更新"，而是任务形态：输出是标签还是文本。

## 十一、易错点

- 自注意力的 self 指的是 QKV **同源**，不是"自己关注自己"这种字面理解
- 掩码加在 **Q 与 K 算出的关联度矩阵**上，不是加在 V 上
- 交叉注意力里 K 和 V 同源（都来自 Encoder），Q 单独来自 Decoder，别把 Q 也说成 Encoder
- 残差解决的是梯度消失和退化，不是过拟合
- 困惑度低 ≠ 生成质量好，这两件事常被混为一谈
- GPT-1 仍然需要微调，Zero-shot 是 GPT-2 才提出的
- BERT 15% 的遮挡里只有一部分换成 `[MASK]`，不是全换
- T5 的相对位置偏置加在注意力得分上，不是加在词向量上，这题最爱考

## 十二、自测

1. 不看笔记说出三种注意力的 Q、K、V 各来自哪里。
2. 掩码矩阵具体把哪些位置置成负无穷？为什么置负无穷而不是置零？
3. 写出残差连接的求导式，说明为什么它能缓解梯度消失。
4. 困惑度低但模型胡说八道，这种情况怎么解释？
5. BERT 和 T5 的掩码策略有什么本质区别？为什么一个适合理解、一个适合生成？
6. 位置编码从绝对到相对，解决了什么绝对位置编码解决不了的问题？
