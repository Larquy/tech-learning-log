# 大模型微调入门：从矩阵到 LoRA

日期：2026-11-03　学习线：人工智能

> 从零基础补起的微调入门。按“矩阵→神经网络一层→训练→语言模型→微调→低秩→LoRA”的顺序走，每讲只讲一个概念。

## 一、起点：模型就是一堆数字表格

模型参数是几十亿个小数，排成矩阵。矩阵乘向量就是加权求和：输出第几个数，等于表格第几行与输入逐项相乘再相加。

模型的全部“计算”都是这个动作，所谓训练就是改表格里的数字。

## 二、一层在做什么

一句话变成一串向量，层的工作是把这串向量加工成另一串，长度不变。

注意力：每个词去判断同一句里其他词与自己的相关程度，按相关度把别人的信息加权取过来。
前馈：每个词各自过一台相同的加工机，把取来的信息再消化一次。

这两步里的矩阵就是参数的主体。同样的两步叠三十几层。

## 三、训练五步

前向猜结果，输出一个概率分布。
和答案比，算损失，正确答案概率越低损失越大。
算梯度，回答每个参数该往哪调、调多少。
反向传播，从最后一层往回把影响逐层推回去。
更新参数，参数减去学习率乘梯度，循环几十万次。

优化器负责“怎么迈这一步”。Adam 除当前梯度外还记两份历史：一阶矩相当于惯性，二阶矩给每个参数单独调步伐。这两份历史每参数一份，是显存吃紧的主因。

batch：一次喂几条样本。显存不够先降 batch。梯度累积能在不加大显存的前提下模拟大 batch——连算几个小 batch 只把梯度累加，攒够再更新一次。

## 四、语言模型与预训练

文本先切成 token，词表约十万。模型输出的是词表上每个 token 的分数，归一化成概率。

训练目标只有一句话：提高真实文本中“下一个词”的预测概率。文本本身就是答案，所以能吃到几万亿字。

生成时按概率选一个词，拼回输入，再预测下一个，逐个吐出来，这叫自回归。

预训练给了语言能力、世界知识和模仿能力。缺私有数据、缺时效、不保证输出格式。补的办法分三种：提示改输入、检索挂资料、微调改行为。

## 五、微调在改什么

形式与预训练相同，只是数据换成几千条“输入—输出”样本。

三种常见目的：指令微调（学会听指令）、领域适应（熟悉行业语料）、任务专用（学会一件事）。

经验值：学习率比预训练小一到两个数量级，轮数一到三遍，数据质量重于数量。

灾难性遗忘是新任务覆盖旧能力。缓解手段：小学习率、少轮数、混入通用样本、用 LoRA 限制改动维度。判断方法：微调前后在同一组通用题上各测一遍。

## 六、低秩：LoRA 的立足点

100 个城市两两距离排成 100 乘 100 的表，一万个数。但这张表由每个城市的两个坐标决定，两百个数就够。一万个数字实际只承载两百个数字的信息量。

秩就是这个“真正独立的因素个数”。距离表秩为 2。

LoRA 的假设：微调要加的那张 4096 乘 4096 的改动表，也是由少数因素决定的。于是不存大表，只存两个瘦表，一个 4096 乘 8，一个 8 乘 4096，相乘近似还原。

存储从 1670 万降到 6.5 万，二百五十倍。

## 七、LoRA 的搭法

W 冻住，旁路为 B 乘 A。A 是 r 乘 k，随机初始化；B 是 d 乘 r，全零初始化。这样初始时旁路输出为零，不破坏原模型，同时 B 能拿到非零梯度。

前向为 Wx 加上 alpha 除以 r 再乘 BAx。alpha 除以 r 的作用是让 r 变化时量级不变，不必重调学习率。

常见配置：r 取 8 或 16，alpha 取 16 或 32，加在注意力的查询和值矩阵上最省参数，效果不够再铺到所有线性层。

参数量为 r(d+k)，比全参少三个数量级，训练时不需要存大表的梯度和优化器状态。
