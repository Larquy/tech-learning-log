# N 元随机变量：函数分布 · 卷积公式 · 常见分布

日期：2026-10-14　课程：概率统计

> 本篇是课堂纪要的整理版，按「定义 → 离散型函数分布 → 和的分布与卷积 → 常见分布可加性 → 二项分解与独立同分布 → 几何分布与三项分布」重排。

## 一、N 元随机变量的映射与分布

- 把 **N 个随机变量**看作从样本空间到向量空间 $\mathbb{R}^N$ 的**映射**，每个分量都是随机变量
- **联合分布函数**：各分量**同时**小于等于对应实数的概率，即
  $F(x_1,\dots,x_N)=P(X_1\le x_1,\ \dots,\ X_N\le x_N)$
- **边缘分布**：对联合分布函数中**除目标变量外的其余变量取极限**（取正无穷）得到的分布

## 二、独立性与连续型的核心等价条件

- **独立性等价于联合密度可分解**：N 元随机变量相互独立，等价于**联合概率密度等于各边缘密度的乘积** ——
  后续计算主要就用这个式子
- **连续型定义**：分布函数能写成 **N 重积分**形式时，被积函数称为**联合概率密度**
- 在连续点处：**联合密度 = 分布函数的 N 阶混合偏导数**

## 三、离散型二元随机变量函数的分布

### 通用计算方法

**核心原理**：已知联合分布率与函数 $g$，求 $Z=g(X,Y)$ 的分布率时，把**使 $Z$ 取值相同**的所有 $(X,Y)$ 组合**对应的概率合并相加**。

与一元情形**没有本质区别**，底层都是「相同取值的概率合并」。

### 示例：4 个 0-1 元素构成的行列式

- 变量设定：四个位置元素都服从 0-1 分布，行列式 $S$ 只取 **0、1、-1** 三个值，共 **16 种组合**
- $P(S=1)$ 的计算含两种情形：
  1. 主对角线为 1、副对角线为 0 → 概率 $p^2q^2$
  2. 另外两种**置换**情形 → 每种概率 $p^3q$
- 由行列式**交换两行反号**的性质，知 $P(S=1)=P(S=-1)$
- $P(S=0)$ 用 $1-P(S=1)-P(S=-1)$ 得到

### 最大值与最小值的几何意义

| 函数 | 事件构成 | 几何图像 |
|---|---|---|
| $Z=\max=n$ | $(X=n,\ Y\le n)\cup(X<n,\ Y=n)$（两事件互斥） | 平面整数格点中**横坐标或纵坐标等于 n、另一坐标不超过 n** 的 **L 形**点集的概率之和 |
| $Z=\min=n$ | $(X=n,\ Y\ge n)\cup(X>n,\ Y=n)$ | 点 $(n,n)$ 及其**右上方射线**上的整数点概率之和 |

**离散 → 连续的类比**：离散型里「整数点概率求和」，在连续型里就对应**相应区域上的积分**。

## 四、和的分布与卷积公式

### 离散型和的分布率

- **完备事件组拆分**：$Z=X+Y=n$ 等价于所有满足 $i+j=n$ 的 $(X=i,\ Y=j)$ 事件之并；
  这些事件构成**完备事件组**，故

  $$P(Z=n)=\sum_{i}P(X=i,\ Y=n-i)$$

  求和遍历所有整数 $i$
- **几何意义**：$P(Z=n)$ 就是**直线 $x+y=n$ 上所有整数格点**的联合概率之和

### 非负整数限制下的卷积公式

当 $X$、$Y$ 都取非负整数时，求和下标 $i$ 从 $0$ 到 $n$：

$$P(Z=n)=\sum_{i=0}^{n}P(X=i)\,P(Y=n-i)$$

这就是**离散型卷积公式**。

## 五、用卷积验证典型分布的可加性

| 分布 | 结论 | 证法 |
|---|---|---|
| **泊松** | $X\sim P(\lambda_1)$、$Y\sim P(\lambda_2)$ 独立 $\Rightarrow Z=X+Y\sim P(\lambda_1+\lambda_2)$ | 代入卷积公式，用**二项式定理**整理 |
| **二项** | $X\sim B(n,p)$、$Y\sim B(m,p)$ 独立 $\Rightarrow Z\sim B(n+m,p)$ | ① 卷积公式 + 组合恒等式 ② **伯努利试验模型**：$n+m$ 次独立重复试验的成功次数自然服从 $B(n+m,p)$ |

**与深度学习的关联**：人工智能大模型里**卷积神经网络**所用的卷积运算，与概率论中的**离散卷积**在数学形式上相近，都是基本的数据运算。

## 六、二项分布分解与独立同分布

### 分解为 0-1 分布之和

- 只要 $n\ge 2$，$B(n,p)$ 对应的随机变量 $S$ 就可以**逐步拆分**成两个更小参数的二项变量之和，最终分解为 **n 个参数为 $p$ 的 0-1 分布（两点分布）**之和
- **指示变量（示性量）**：每个 $S_i$ 表示第 $i$ 次伯努利试验是否成功，成功取 1、否则取 0

### 独立同分布（i.i.d.）

- **定义**：分解得到的 $S_i$ **相互独立**且**均服从同一参数 $p$ 的 0-1 分布**
- **后续用途**：把复杂随机变量分解为**简单独立同分布变量之和**，这个手法在后面的**期望、方差、极限定理**里会反复用

## 七、几何分布求和与三项分布

### 命中两次所需的次数

- **问题设定**：独立重复试验，直到**成功两次**为止所需次数 $Z$ 的分布率
- **概率公式**：$Z=k$ 表示前 $k-1$ 次恰好成功 1 次、第 $k$ 次成功，故

  $$P(Z=k)=(k-1)\,p^{2}q^{k-2},\qquad k\ge 2$$

### 两个几何变量之和与原问题的关系

- 设 $X_1$、$X_2$ 独立同分布于 $\mathrm{Geom}(p)$，$Y=X_1+X_2$ 表示**先后两次首次成功**所需的总次数，
  与直接定义的 $Z$ 分布相同：

  $$P(Y=k)=\sum_{i=1}^{k-1}pq^{\,i-1}\cdot pq^{\,k-i-1}=(k-1)p^{2}q^{k-2}$$

  与上式一致，猜想的分布相同得到验证
- **模型解释**：在**同一独立重复试验序列**中，$Y$ 与 $Z$ 实际上是**同一个随机变量**，只是计数方式不同

### 三项分布的边缘合并性质

- **三项分布定义**：$n$ 次独立重复试验有 $A_1,A_2,A_3$ 三个结果，概率分别为 $p_1,p_2,p_3$；
  记 $S_i$ 为 $A_i$ 发生的次数，则 $(S_1,S_2,S_3)$ 服从**三项分布**
- **$S_1+S_2$ 的分布**：把 $A_1$ 与 $A_2$ 视为同一类事件合并，每次试验「属于 $A_1$ 或 $A_2$」的概率为 $p_1+p_2$，
  故 $S_1+S_2\sim B(n,\ p_1+p_2)$

## 八、本篇要点清单（考前扫一眼）

1. 相互独立 $\iff$ **联合密度 = 各边缘密度之积**，后续计算主要靠这个式子
2. **联合密度 = 分布函数的 N 阶混合偏导**；分布函数 = 密度的 N 重积分；边缘分布靠对其余变量取极限
3. 离散型函数分布：**把 $Z$ 取值相同的组合概率合并相加**，与一元情形同理
4. $Z=\max=n$ 是 **L 形**点集，$Z=\min=n$ 是**点 $(n,n)$ 及右上方射线**；连续型里换成区域积分
5. **卷积公式** $P(Z=n)=\sum_i P(X=i,\ Y=n-i)$；$X,Y$ 取非负整数时 $i$ 从 $0$ 到 $n$
6. 可加性：泊松 $\lambda_1+\lambda_2$；二项 $B(n+m,p)$（**伯努利模型最直观**）
7. $B(n,p)$ 可分解为 **n 个 0-1 分布之和** → **独立同分布（i.i.d.）**，后面期望/方差/极限定理反复用
8. 命中两次所需次数：$P(Z=k)=(k-1)p^{2}q^{k-2}$，等于两个 $\mathrm{Geom}(p)$ 之和（同一序列，只是计数方式不同）
9. 三项分布合并：$S_1+S_2\sim B(n,\ p_1+p_2)$
