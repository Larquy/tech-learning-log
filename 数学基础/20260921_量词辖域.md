# 量词辖域的收缩与扩张（为什么只有箭头左边要换）

日期：2026-09-21　科目：离散数学

## 结论先行

**量词往外提时要不要改名，只看它是不是在箭头（→）的左边。**

- 在 `∧` / `∨` 里、或在箭头**右边** → **量词原样搬出去**
- 在箭头**左边** → **∀ ↔ ∃ 互换**再搬

根据：`A→B ≡ ¬A ∨ B`，箭头左边一展开就落到"非"后面，而"非"会把量词翻面（`¬∀xP(x) ≡ ∃x¬P(x)`）。

## 八条公式

| 组 | 形式 | 出门后 |
|---|---|---|
| A | ④∃ `∀xP(x) ∨ Q ≡ ∀x(P(x)∨Q)`（①②③④ 同类） | 不变 |
| B | ⑤⑥ `Q → ∀xP(x) ≡ ∀x(Q→P(x))` | 不变（在箭头右边） |
| C | ⑦ `∀xP(x) → Q ≡ ∃x(P(x)→Q)` | **∀ 变 ∃** |
| C | ⑧ `∃xP(x) → Q ≡ ∀x(P(x)→Q)` | **∃ 变 ∀** |

前提：**Q 里不能含 x 的自由出现**。

## 只能单向推的那五条（同套路：捆着说 ⇒ 拆开说）

| 式 | 人话 | 反例 |
|---|---|---|
| `(∀x)P∨(∀x)Q ⇒ (∀x)[P∨Q]` | 全 P ⇒ 每人至少沾一个 | 张三只有 P、李四只有 Q |
| `(∃x)[P∧Q] ⇒ (∃x)P∧(∃x)Q` | 有人两样都占 ⇒ 有人 P 且有人 Q | 同上，没人两样都占 |
| `(∀x)[P→Q] ⇒ (∀x)P→(∀x)Q` | 凡 P 都 Q ⇒ 全 P 则全 Q | 反向不成立 |
| `(∃x)P→(∀x)Q ⇒ (∀x)[P→Q]` | 有人 P 就全 Q ⇒ 凡 P 者各自 Q | 有人戴眼镜 ≠ 人人戴 |
| `(∀x)[P↔Q] ⇒ (∀x)P↔(∀x)Q` | 每人同真同假 ⇒ 整体同真同假 | 反向不成立 |

`∀` 配 `∧`、`∃` 配 `∨` 这两对可以**双向等价**；其他组合只能单向推。

## 数值验证（穷举 3 元素论域的所有 P、Q 子集）

八条等价式全部成立；五条蕴含式**正向全成立、反向全部有反例**。

## 踩的坑

1. 忘了前提"Q 不含 x"，直接套公式。
2. 把 `(∀x)(P(x)∨Q(x))` 当成能反推 `(∀x)P(x) ∨ (∀x)Q(x)`。
