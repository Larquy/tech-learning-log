# 条件概率、独立性与系统可靠性

日期：2026-09-21　科目：概率统计

## 结论先行

- **独立**的定义：`P(AB) = P(A)P(B)`，等价于 `P(A|B) = P(A)`。
- **互斥 ≠ 独立**：互斥是"不能同时发生"，独立是"互不影响"，两个概念无关。
- 看到 `P(A|B) + P(A|B̄) = 1` 这类对称条件 → 化成 `P(A|B) = P(A)` → **独立**。

## 典型题型

**1. 由条件概率方程反推独立性**
设 `P(A|B) + P(Ā|B̄) = 1`：
```
P(A|B̄) = 1 − P(Ā|B̄) = P(A|B)
P(A) = P(A|B)P(B) + P(A|B̄)P(B̄) = P(A|B)   →  A 与 B 独立
```

**2. 求条件概率（先补全再算）**
已知 A、B 互斥，A⊥C、B⊥C，`P(A)=0.5, P(B)=0.3, P(C)=0.4`，求 `P(A∪B|C̄)`：
```
P(C̄)=0.6
P(A C̄) = P(A) − P(A)P(C) = 0.5 − 0.2 = 0.30
P(B C̄) = 0.3 − 0.12 = 0.18
P(A∪B|C̄) = (0.30 + 0.18) / 0.60 = 0.8
```
**巧解**：独立 ⇒ 在 `C̄` 条件下概率不变（仍是 0.5 与 0.3），互斥 ⇒ 直接相加 = **0.8**。

**3. 系统可靠性**
| 结构 | 可靠度 |
|---|---|
| 串联（都要工作） | `R = ∏pᵢ` |
| 并联（一个工作即可） | `R = 1 − ∏(1−pᵢ)` |
| 混联 | 分块算再相乘/相加 |

例：两个并联 + 两个串联 → `R = [1−(1−p)²]·p² = 2p³ − p⁴`
（p=0.9 时：0.99 × 0.81 = 0.8019）

## 踩的坑

1. 问条件概率时**忘了除以条件概率**（如忘除 `P(C̄)=0.6`）。
2. 把"互不相容"当成"独立"用 —— 题目里独立往往是**额外给的条件**。

## 还没搞懂的

- 三个事件两两独立但整体不独立的标准反例，想自己构造一遍。
