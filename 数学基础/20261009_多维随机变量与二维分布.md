# 多维随机变量：二维定义 · 联合与边缘分布律 · 条件分布与独立性 · 二元分布函数

日期：2026-10-09　课程：概率统计

> 课堂纪要整理版。主线：**为什么要多维 → 离散型的联合/边缘/条件分布 → 独立怎么判 → 二元分布函数（框架，考试基本不考）→ 两钱包悖论**。

## 一、为什么要有"多维"随机变量

**必要性**：不少随机试验的结果**一个指标说不清**，必须用两个甚至多个指标共同描述 ✓

| 典型场景 | 需要的指标 |
|---|---|
| 砖头质量 | 抗压强度、抗折强度 |
| 儿童发育 | 身高、体重、胸围、头围 |
| 企业效益 | 劳动生产率、资金产出率 |

**数学定义**：同一概率空间上的两个随机分量 $X,Y$ 构成**二维随机变量**（也叫二元随机变量、二维随机向量）✓
- 本质：**从样本空间到平面 $\mathbb{R}^2$ 的映射**，取值对应平面上的一个**点** ✓
- 与一元（到 $\mathbb{R}$ 的映射）的区别就在这 ✓

## 二、离散型：联合分布律与边缘分布律

### 1. 不放回取球实例（盒中 10 球：7 红 3 黑，不放回取两次）

$X$ = 第一次结果（1 红 / 0 黑），$Y$ = 第二次结果（1 红 / 0 黑）✓

| 概率 | 计算 |
|---|---|
| $P(X=1,Y=0)$ | $\frac{7}{10}\times\frac{3}{9}$ |
| $P(X=1,Y=1)$ | $\frac{7}{10}\times\frac{6}{9}$ |
| $P(X=0,Y=0)$ | $\frac{3}{10}\times\frac{2}{9}$ |
| $P(X=0,Y=1)$ | $\frac{3}{10}\times\frac{7}{9}$ |

**把这四个概率排成表格 = 联合分布律** ✓

### 2. 边缘分布律怎么来

- $X$ 的边缘分布律 = 联合分布律里**对应行相加** ✓
- $Y$ 的边缘分布律 = 联合分布律里**对应列相加** ✓
- 本质：**边缘分布律就是这个变量自己的分布律** —— 加"边缘"两个字只是为了强调它与二元随机变量的关联 ✓
- 💡 $Y=0$ 与 $Y=1$ 构成**完备事件组**，所以 $P(X=0)=P(X=0,Y=0)+P(X=0,Y=1)$ —— 这就是**全概率公式的思想** ✓

### 3. 联合分布律的两条基本性质

1. 每个概率 $\ge 0$ ✓
2. 全部概率之和 $=1$（归一性）✓
3. ⚠️ **概率为零的项必须在表格里明确写出，不能省略** —— 省略会让表格含义产生歧义 ✓
   （这与**一元**离散型"零概率项可以省"的做法**不同** ✓）

### 4. 补充案例：抽号码球

每个编号的球只有一个 → **取到相同号码的概率为 0**；取到某一对不同号码的概率都是 $\frac14\times\frac13=\frac{1}{12}$ ✓
两个变量的**边缘分布律**中，取到每个号码的概率都是 $\frac14$ ✓

## 三、条件分布与独立性

### 1. 条件分布（不放回取球例子）

$$P(Y=1\mid X=0)=\frac79,\qquad P(X=0\mid Y=0)=\frac29,\qquad P(X=0\mid Y=1)=\frac13$$

三者数值各不相同 ✓

💡 **核心意义**：第二次取球**不会反过来改变第一次的物理过程**，但它**改变了对第一次结果的概率判断** —— 这就是条件概率的意义 ✓

📌 条件分布一般**不单独列完整分布律**（条目太多），**按需算特定的条件概率**即可 ✓


### 2. 独立性（离散型）

**定义**：对**任意**取值 $i,j$，都有
$$P(X=i,\;Y=j)=P(X=i)\,P(Y=j)$$
则称 $X$ 与 $Y$ **相互独立** ✓

- **有放回**取球时，联合分布律里每个概率都等于对应边缘概率之积（如 $P(X=1,Y=1)=\frac{7}{10}\times\frac{7}{10}$）✓
- 反过来：**已知边缘分布律 + 已知独立** → 直接相乘就得到联合分布律 ✓（省一半计算量 ✓）

### 3. 独立性的等价判定条件

| 等价说法 | 内容 |
|---|---|
| ① 分布函数形式 | $F(x,y)=F_X(x)\,F_Y(y)$ ✓ |
| ② 可分离变量 | 存在 $g(x)$、$h(y)$ 使 $F(x,y)=g(x)h(y)$ ✓ |
| ③ 区间事件的独立性 | 对任意区间，事件 $\{x_1<X\le x_2\}$ 与 $\{y_1<Y\le y_2\}$ 相互独立；**反之亦然** ✓ |

- 证明思路（了解）：依赖分布函数的**相容性公式**与**因式分解**，或用**集合差事件的独立性引理**递推完成 ✓

## 四、二元分布函数（统一框架，考试基本不涉及）

### 1. 定义与几何意义

$$F(x,y)=P(X\le x,\;Y\le y)$$
几何意义：取值落入**以 $(x,y)$ 为右上角的无穷矩形**区域内的概率 ✓

### 2. 五条基本性质

1. 取值范围在 $0$ 到 $1$ 之间 ✓
2. **固定一个变量时，对另一个变量单调递增** ✓
3. 任一变量趋于 $-\infty$ 时，$F\to 0$（逼近不可能事件）✓
4. 两变量都趋于 $+\infty$ 时，$F\to 1$（逼近必然事件）✓
5. 对**每个变量都右连续** ✓

⚠️ 涉及极限的性质，**严格证明要靠概率的可列可加性** —— 不能简单化成一元情形来处理 ✓

### 3. 相容性公式（矩形概率）

$$P\big(x_1<X\le x_2,\;y_1<Y\le y_2\big)=F(x_2,y_2)-F(x_2,y_1)-F(x_1,y_2)+F(x_1,y_1)$$

- 证明思路：把该矩形分解成**四个互斥区域**的并，用概率可加性 + 代数抵消 ✓
- 结论：**满足上述五条性质 + 相容性**的二元函数，必是某个二维随机变量的分布函数 ✓

### 4. 边缘分布函数与联合分布函数的关系

$$F_X(x)=\lim_{y\to+\infty}F(x,y),\qquad F_Y(y)=\lim_{x\to+\infty}F(x,y)$$

### 5. 这门课里它的"定位"（很重要，别花错力气）

| 类型 | 核心工具 |
|---|---|
| **离散型** | **联合分布律 + 边缘分布律** ✓ |
| **连续型** | **概率密度函数** ✓ |
| 二元分布函数 | 只起**过渡与统一框架**作用（计算繁琐、要分块），**后续几乎不再用，考试基本不涉及** ✓ |

## 五、两钱包悖论（课堂上的思想实验）

### 错误的推理

假设甲钱包金额为 $a$ → 认为乙钱包以 $\frac12$ 概率是 $2a$、以 $\frac12$ 概率是 $\frac a2$ → 于是"交换更划算"，且对**任意** $a$ 都成立 ✗

👉 讲者指出：**这个假设不可能对所有 $a$ 同时成立**，所以推理无效 ✓

### 正确的建模

设**钱少者**金额为随机变量 $Z$ → 两人钱包组合只有两种可能：$(Z,\,2Z)$ 或 $(2Z,\,Z)$ ✓

- "交换"只是这两种状态的**互换** ✓
- 无论处于哪种状态，**两人平均金额都是 $\frac{3Z}{2}$** → **交换不改变期望值** ✓

### 悖论的根源

**把条件概率当成了无条件概率来用** —— 忽略了 $Z$ 本身的分布约束 ✓

## 六、本篇要点清单

1. 二维随机变量 = 样本空间到 $\mathbb{R}^2$ 的映射（取值是平面上的点）✓
2. **边缘分布律 = 联合分布律按行/按列相加** ✓
3. 联合分布律里**零概率项也要写出来**（与一元不同）✓
4. 条件概率的意义：**不改变物理过程，但改变概率判断** ✓
5. 独立 ⟺ $P(X=i,Y=j)=P(X=i)P(Y=j)$ ⟺ $F(x,y)=F_X(x)F_Y(y)$ ⟺ **可分离变量** ✓
6. 离散型用**分布律**、连续型用**密度**；**二元分布函数只是过渡，考试基本不涉及** ✓
7. 两钱包悖论：错误在于**把条件概率当成无条件概率**；实际上交换不改变期望 ✓
