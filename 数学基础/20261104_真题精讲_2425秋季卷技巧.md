# 概率统计真题精讲：2024-2025 秋季卷

日期：2026-11-04　课程：概率统计（理工）

> 这份卷子的六道填空和六道解答，只记技巧，不全抄解答。每一条都是能在考场上省时间的动作。

## 一、填空：对立事件计数

三枚骰子至少两枚相同。直接数要分“恰好两枚”和“三枚全同”，容易漏。

反过来数“三枚互不相同”：6×5×4 = 120，除以 216 得 5/9，所求 4/9。

**动作**：见“至少”，先算反面。

## 二、填空：包含关系连乘

A ⊂ B ⊂ C，已知 P(A|B) 与 P(B|C)，求 P(A|C)。

因为层层包含，交集就是小的那个，于是

P(A|C) = P(A)/P(C) = [P(A)/P(B)]·[P(B)/P(C)]

直接连乘两个已知条件即可。

**动作**：包含关系下，条件概率等于两个边缘概率之比，可以拆开连乘。

## 三、填空：圆盘上到原点的距离

单位圆盘均匀取点，R 为到原点距离，求 E(R)。

先写 F_R(r) = 面积比 = r²，密度 2r，再积分得 2/3。

**更快**：E(R) = ∫₀¹ P(R>r)dr = ∫₀¹(1−r²)dr = 2/3，不用求导。

**动作**：非负随机变量若分布函数好写，直接用生存函数积分求期望。

## 四、填空：指数分布服务时间

两柜台同时在服务，第三人丙最后办完的概率。

把“丙最后”翻译成不等式：min(A,B) + C > max(A,B)，即 C > |A−B|。

关键事实：两个独立同分布指数变量的差的绝对值，仍服从同参数指数分布。

于是 C 与 |A−B| 独立同分布，谁大谁小的概率各半，答案 1/2。

**动作**：记住“指数相减取绝对值还是指数”。这条能省一次二重积分。

## 五、填空：对称性求期望

X、Y、Z 独立同分布，求 E[X/(X+Y+Z)]。

三项同分布所以期望相等，三项和为 1，于是每项 1/3。

**动作**：形如 E[某个变量／全部变量之和]，只要同分布，答案就是 1/n。不必积分。

## 六、解答：两个几何分布取最小

Z = min(X,Y)，求分布列。

不求 P(Z=n)，改求 P(Z≥n)：最小值不小于 n 等价于两者都不小于 n，独立可乘，得 (1−r)^(n−1)，其中 r = 1−(1−p₁)(1−p₂)。

再差分：P(Z=n) = P(Z≥n) − P(Z≥n+1) = r(1−r)^(n−1)。

结论：仍是几何分布，参数 r 是“至少一次成功”的概率。

**动作**：最值分布先写分布函数或生存函数，别直接算单点概率。

## 七、解答：差的密度，几何法与卷积

X、Y 独立均匀于 (0,1)，Z = X−Y。

**几何法**：在单位正方形里画 y = x − z，取直线上方。z 在 (0,1) 时被切掉一个直角边 1−z 的等腰直角三角形，所以 F = 1 − (1−z)²/2。求导得三角形密度。

**卷积是什么**：离散里两个骰子求“和为 7”，把所有配对列出来加起来，这就是卷积。连续版把“列出配对”变成“固定 x，令另一变量等于 z−x，乘密度再对 x 积分”。

$$f_Z(z)=\int f_X(x)f_W(z-x)\,dx$$

积分限靠两个区间取交集定：x 要在 (0,1)，且 z−x 要在 (−1,0)，即 x 在 (z,z+1)。

z 在 (−1,0) 时交集长 z+1，z 在 [0,1) 时长 1−z。

**动作**：求分布函数用几何法，求密度用卷积或对分布函数求导。

## 八、解答：圆盘均匀分布的五问

联合密度取面积倒数 1/π。

边缘密度要按竖直弦长算，f_X(x) = (2/π)√(1−x²)，不是常数。所以联合均匀不等于边缘均匀。

独立性：乘起来和 1/π 不等，故不独立。几何上，x 靠中间时 y 的活动范围大，两者互相提供信息。

条件密度 = 联合 ÷ 边缘 = 1/(2√(1−y²))，给定 y 时 x 在弦上均匀。

**动作**：判断独立性只能老实算两条边缘再相乘比较，不能凭“看起来均匀”下结论。

## 九、解答：绝对值的期望与方差

X 服从泊松(1)，Y = |X−1|。

求 E(Y) 按定义逐项加：k=0 贡献 e⁻¹，k=1 贡献 0，k≥2 用 (k−1)/k! = 1/(k−1)! − 1/k! 拆项，得 e⁻¹。合计 2/e。

求方差时先平方，Y² = (X−1)²，绝对值自动消失，展成 E(X²) − 2E(X) + 1 = 1。所以 D(Y) = 1 − 4/e²。

**动作**：带绝对值的量求方差，先平方消掉绝对值。
