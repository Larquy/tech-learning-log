# 二元连续型随机变量：联合密度 · 边缘密度 · 条件密度 · 独立性判定

日期：2026-10-10　课程：概率统计

> 本篇是课堂纪要的整理版，按"**密度怎么来 → 怎么算积分 → 边缘/条件密度 → 怎么判独立**"五块重排。

## 一、联合分布函数与联合概率密度

| 结论 | 写法 |
|---|---|
| **积分定义** | 若存在 $f(s,t)$ 使 $F(x,y)=\int_{-\infty}^{x}\!\!\int_{-\infty}^{y}f(s,t)\,dt\,ds$，则 $f$ 就是**联合概率密度** ✓ |
| **微分关系** | 在 $f$ 连续的点：$f(x,y)=\dfrac{\partial^{2}F(x,y)}{\partial x\,\partial y}$ ✓（**积分上限求导用两次**：先对外层变量求偏导去掉外层积分，再对内层变量求偏导并替换积分上限 ✓）|

**三条基本性质**：
1. **非负性**：$f(x,y)\ge 0$（整个平面）✓
2. **规范性**：$\int_{-\infty}^{+\infty}\!\!\int_{-\infty}^{+\infty}f(x,y)\,dx\,dy=1$ ✓
3. **概率公式**：$P\big((X,Y)\in G\big)=\iint_G f(x,y)\,dx\,dy$ ✓（**属自然结论，无需证明** ✓）

## 二、二重积分怎么算（概率统计里的都偏简单）

### 第一步永远是：**画区域** ⭐（课程反复强调）

- 密度常常是**分块定义**的，很多区域上是 0 → **只在非零区域上算积分** ✓

### 矩形区域 + 可分离变量

若在矩形区域上 $f(s,t)=g(s)h(t)$（可分解成 x 的函数 × y 的函数），则
$$\iint_{\text{矩形}}g(s)h(t)\,ds\,dt=\Big(\int g\Big)\Big(\int h\Big)$$
**与积分变量无关的因子可提到积分号外**；内层积分算完是常数，再算外层 ✓

### 归一化常数示例

- 在第一象限的非零区域上算二重积分，令其等于 1 → 求出 **$K=2$** ✓
- 过程中用**换元 $t=e^{-s}$**，算得积分结果为 **$\frac{1}{100}$**，反推 $K=2$ ✓
- 📌 课程说明：概率统计里遇到的**二重积分函数形式都很基础**，不用怕 ✓

## 三、平面均匀分布与几何概型

**定义**：区域 $G$ 面积有限、面积为 $A$，若
$$f(x,y)=\begin{cases}\dfrac1A,&(x,y)\in G\\[4pt]0,&(x,y)\notin G\end{cases}$$
则称 $(X,Y)$ 服从 $G$ 上的**均匀分布** ✓

- 均匀分布 ⟺ **几何概型**：$P\big((X,Y)\in D\big)=\dfrac{D\text{ 的面积}}{G\text{ 的面积}}$ ✓
- ⚠️ **几何概型的局限**：只能处理"面积比"的简单概率；**要算期望、方差等数字特征或更复杂的量，必须回到密度积分** ✗

### 两类典型区域的独立性差异（结论先记住，证明后面再讲）

| 区域 | 独立性 |
|---|---|
| **矩形**均匀分布 | $X$ 与 $Y$ **相互独立** ✓ |
| **圆盘**均匀分布（如半径 2、圆心在原点）| $X$ 与 $Y$ **不独立** ✗ |


## 四、边缘概率密度

**定义（对另一个变量在全轴积分）**：
$$f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy,\qquad f_Y(y)=\int_{-\infty}^{+\infty}f(x,y)\,dx$$

**几何意义**：边缘密度 = **沿一条平行于坐标轴的直线**对联合密度积分 ✓（把另一维"压扁"✓）

### 三角形区域例题（分段讨论是重点）

区域：$\{(x,y):0\le x\le y\le 1\}$（即由 $y=x$、$y=1$、$x=0$ 围成的三角形，面积 $\frac{1}{2}$）→ 密度 $f=2$ ✓

| 目标 | 分段 | 结果 |
|---|---|---|
| **$f_Y(y)$** | $y\le 0$ 或 $y>1$ → **0**；$0<y<1$ → 只有 $[0,y]$ 段被积函数为 2 | $f_Y(y)=2y$（$0<y<1$）✓ |
| **$f_X(x)$** | $x\le 0$ 或 $x>1$ → **0**；$0<x<1$ → 只有 $[x,1]$ 段被积函数为 2 | $f_X(x)=2(1-x)$（$0<x<1$）✓ |

> 📌 **校对说明**：纪要里提到"直线 $2x+y=2$"，但那条线围出的三角形面积是 1（密度应为 1）；而纪要给出的两个边缘密度 $2y$ 与 $2(1-x)$ 对应的是区域 $0\le x\le y\le 1$ ✓ 这里按**结果自洽的区域**记录 ✓

## 五、条件概率密度

### 为什么连续型不能直接套 $P(A|B)=\dfrac{P(AB)}{P(B)}$

- 离散型可以：条件分布律 = 联合分布律 ÷ 边缘分布律（条件事件概率非零 ✓）
- 但连续型 **$P(X=x)=0$** ✗ → 分母为 0，定义不出来 ✓

### 正式定义

$$f_{Y|X}(y|x)=\frac{f(x,y)}{f_X(x)}\qquad(\text{在 }f_X(x)>0\text{ 处})$$
- 在 $f_X(x)=0$ 处，**条件密度无定义（不存在/无意义）** ✓
- 直观（身高体重例）：联合密度描述整体分布；**$f_{Y|X}(y\,|\,1.6)$ 描述"身高 1.6 米的人"的体重分布** ✓

### 用极限说明"定义得合理"（理解思路，不必背）

考虑 $P(Y\le y\mid x_1<X\le x_2)
=\dfrac{\iint_{\text{带状区域}}f}{\int_{x_1}^{x_2}f_X(x)\,dx}$，令 $x_2\to x_1$：
分子分母都趋于 0 → 用**罗比达法则**对 $x_2$ 求导 → 得
$$\lim_{x_2\to x_1}\frac{\int_{-\infty}^{y}f(x_2,t)\,dt}{f_X(x_2)}=\frac{\int_{-\infty}^{y}f(x_1,t)\,dt}{f_X(x_1)}$$
这可以看成 $X=x_1$ 条件下 $Y$ 的**条件分布函数**；它对 $y$ 的被积函数就是**条件密度** ✓
（老师说明：这个推导**不严格**，但有助于理解"从离散型过渡到连续型"的思路 ✓）

### 反过来：条件密度 × 边缘密度 = 联合密度

**例**：$X\sim E(1)$，且在 $X=x>0$ 条件下 $Y\sim U[0,x]$
- 条件密度：$f_{Y|X}(y|x)=\dfrac1x$（$0\le y\le x$）✓
- 边缘密度：$f_X(x)=e^{-x}$（$x>0$）✓
- **相乘**：$f(x,y)=\dfrac{e^{-x}}{x}$（成立区域 $0\le y\le x,\ x>0$）✓
- 注意：$x\le 0$ 时边缘密度为 0 → 联合密度**必为 0**，条件密度**无定义** ✓

## 六、边界取值不影响积分（一个小结论，考试爱埋）

- 密度在**区域边界**上的取值（是 0 还是不是 0）**不影响二重积分结果** ✓
- 原因：**密度本质上是由二重积分定义的，不是由导数定义的** —— 改变低维集合上的值，积分值不变 ✓（与定积分里"改变有限个点的值不影响积分"同理 ✓）

## 七、独立性判定（本节最实用）

### 等价条件

| 层面 | 独立 ⟺ |
|---|---|
| 分布函数 | $F(x,y)=F_X(x)F_Y(y)$ ✓ |
| 概率密度 | $f(x,y)=f_X(x)f_Y(y)$ ✓（对 $F=F_XF_Y$ 两边求**二阶混合偏导**即可验证 ✓）|

### 四点乘积等式判定法

若 $X,Y$ 独立，则对**任意四个实数** $x_1,x_2,y_1,y_2$：
$$F(x_1,y_1)\,F(x_2,y_2)=F(x_1,y_2)\,F(x_2,y_1)$$
- 这是独立性的**充分条件**（老师称反向也成立，课上不证 ✓）
- **用法**：取三个点在**密度非零区域内**、一个点在**区域外** → 让等式一边为 0、另一边非 0 → **立刻判出不独立** ✓

### 矩形必要条件（**最快的一招**）

> 若 $X,Y$ 独立 → 联合密度**非零区域必须是矩形**（含广义矩形：多个对齐矩形的并集）✓

- 这是**必要条件，不是充分条件** ✓ —— 但足够用来**快速排除**：**只要非零区域不是矩形，立刻判不独立** ✓
- 典型：**圆盘**上均匀分布 → 非零区域不是矩形 → **直接判 $X,Y$ 不独立**，**不用算边缘密度** ✓
- 三角形、圆形均匀分布同理（非矩形 → 不独立 ✓）

### 为什么值得用几何判别

**看形状比算积分又快又不容易错** ✓ 考试时间紧时先用它排除，剩下再老实算 ✓

## 八、本篇要点清单（考前扫一眼）

1. 密度 = 分布函数的**二阶混合偏导**；分布函数 = 密度的**二重积分** ✓
2. **算二重积分第一步永远是画区域**，且只在密度非零区域上积 ✓
3. 矩形 + 可分离 → **两个定积分相乘** ✓
4. 均匀分布：密度 $=1/A$；概率 $=$ **面积比**；但求数字特征必须用积分 ✗
5. **矩形均匀 ⇒ 独立；圆盘/三角形均匀 ⇒ 不独立** ✓
6. 边缘密度 = 沿一条直线积另一维（**分段讨论**别漏 ✓）
7. 条件密度 $=f(x,y)/f_X(x)$（只在 $f_X>0$ 处 ✓）；$P(X=x)=0$ 是"不能直接定义"的根源 ✓
8. **判独立最快的一招：看非零区域是不是矩形** —— 不是矩形就直接不独立 ✓
9. 边界上的取值不影响积分 ✓
