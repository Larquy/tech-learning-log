# 概率统计半期复盘：古典概型与条件概率

日期：2026-11-04　课程：概率统计（理工）

> 半期范围 §1.1 至 §4.1。这篇按“计数、几何、条件、贝叶斯、数字特征”五块梳理，末尾列易错点。

## 一、古典概型

两个前提：结果有限，且每个结果等可能。满足则概率等于有利情形数除以总情形数。

**三件计数工具**：乘法原理、排列（顺序不同算不同）、组合（只看选了谁）。

**分组公式**：n 个元素分 k 组，各组 rᵢ 个，总数 n!/(r₁!r₂!…rₖ!)。这个公式默认组有编号。若只是“分成几堆”且每组等大，还要再除组数的阶乘。

**抽签与顺序无关**：n 张签 k 张有奖，第 m 个人中奖概率恒为 k/n。但一旦前面结果公开，条件概率就变，先验与后验要分清。

**球入盒**：k 个不同球入 N 个不同盒，分母恒为 N^k。指定盒子“恰有 m 个”要乘 C(k,m)；指定盒子“空着”则每个球只能进其余 N−1 个。

**鞋子问题**：“至少有一双”直接数会重复（两整双被数两次），要么减掉 C(5,2)，要么改用对立事件“四只都不成双” C(5,4)·2⁴。见“至少”先想反面。

## 二、几何概型

概率等于长度比或面积比。固定动作：画图，把不等号化成曲线，判断积分区间从哪开始。

例：X、Y 独立均匀于 [0,1]，求 P(XY<1/3)。补集为 y ≥ 1/(3x)，积分从 x=1/3 起（再小则曲线跑出正方形），得 P = (1+ln3)/3。

## 三、贝特朗悖论

“随机取一条弦”配四种样本空间，答案各不相同：中点均匀于圆盘得 1/4，固定一端得 1/3，两端均匀于圆周得 1/3，中点用角度加距离参数化得 1/2。

结论不是概率论有矛盾，而是“随机”必须先定义样本空间。几何概型题要写明样本空间与等可能的含义。

## 四、条件概率

定义 P(B|A) = P(AB)/P(A)。几何意义是把样本空间从 Ω 压缩到 A。

乘法公式 P(AB) = P(A)P(B|A)，三个事件连乘 P(ABC) = P(A)P(B|A)P(C|AB)。

注意 P(B|A) 与 P(A|B) 完全不同。现象如“十次车祸九次快”给的是 P(快|车祸)，说明不了 P(车祸|快)。

不放回抽球题里，已知第二次结果反推第一次，答案常与顺向相同，但过程仍要按定义算。

## 五、全概率与贝叶斯

全概率：把样本空间分成完备事件组（互斥且盖满），P(A) = ΣP(Bᵢ)P(A|Bᵢ)。思路是按来源分情况加权。

贝叶斯：P(Bᵢ|A) = P(Bᵢ)P(A|Bᵢ) / ΣP(Bⱼ)P(A|Bⱼ)。由结果反推原因，分母是全概率。

医学检测例子：患病率 0.1%、灵敏度与特异度均 99% 时，阳性后真患病概率仅约 9%。因为健康人基数大，假阳性绝对数超过真阳性。

## 六、常见分布的期望与方差

| 分布 | 期望 | 方差 | 推导要点 |
|---|---|---|---|
| 泊松 P(λ) | λ | λ | 阶乘矩法，k² = k(k−1)+k |
| 二项 B(n,p) | np | npq | 拆成 n 个独立 0-1 之和 |
| 0-1 | p | pq | |
| 均匀 U(a,b) | (a+b)/2 | (b−a)²/12 | |

泊松的 E(X²) = λ² + λ：用 k! = k(k−1)(k−2)! 约掉，剩下泊松概率和等于 1。

## 七、易错清单

“至少”类题直接数易重复，优先用对立事件。

分子分母必须同口径，一个按组合一个按排列就是错。

分组公式默认组有编号，无编号且等大要再除组数阶乘。

条件概率方向写反，P(B|A) 不是 P(A|B)。

几何概型积分区间起点取错，注意曲线何时跑出区域。

E(XY)=E(X)E(Y) 需要独立，但 E(X)=0 时等号自动成立，别被这种选项骗。
