## 笔记规范

1. **结论先行**：开头一句话说清"这是什么 / 为什么这么做"
2. **能给代码就给代码**：附编译运行命令 + 真实输出
3. **踩的坑单独一节**（最容易忘、最值钱）
4. **还没搞懂的**：诚实留白

## 代码规范

- 命名 `日期_主题.c/.cpp/.py`
- 文件开头注释：题目、思路、编译运行命令
- 提交前保证能编译且跑通
