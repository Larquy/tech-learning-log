# 图论：强分图、单向分图与三类矩阵

日期：2026-11-04　课程：离散数学

> 这一轮做的是有向图的连通性与矩阵表示：强分图与单向分图的求法、连通性的不等式证明、邻接矩阵与可达性矩阵与关联矩阵的写法。

## 一、强分图与单向分图

**强分图**：极大的强连通子图，块内任意两点互相可达。

**单向分图**：极大的单向连通子图，块内任意两点至少一方可达另一方。它比强分图大，且不同单向分图之间允许重叠，不要求划分。

**求法**

先算每点能到达哪些点，互相能到的归成一块，就是强分图。

把每块缩成一个点，画出块之间的箭头，得到缩点 DAG。在 DAG 里找最长的一条链，链上所有块并起来就是一个单向分图。

**易错点**：单向连通的条件弱，“有一方可达”就算数。所以一个只有入边的死点，也能和所有能到它的点并进同一个单向分图。

## 二、连通性证明：不相邻点度数和

**命题**：n 阶无向简单图中，若每对不相邻顶点的度数之和至少是 n−1，则图连通。

**证法**：反设不连通，取一个连通分支 C，含 k 个点（1 ≤ k ≤ n−1）。从 C 内取 u，从 C 外取 v，两点分属不同分支必然不相邻。

u 的邻居只在 C 内，所以 d(u) ≤ k−1。
v 所在的另一块最多 n−k 个点，所以 d(v) ≤ n−k−1。

相加得 d(u)+d(v) ≤ n−2，与题设的 n−1 矛盾。

**骨架**：反设不连通 → 跨分支取点 → 度数分别被各自分支卡住 → 和不足 n−1 → 矛盾。

## 三、三类矩阵

**邻接矩阵**：n×n，a_ij=1 表示 i 到 j 有边。看的是点与点。

**可达性矩阵**：n×n，p_ij=1 表示 i 能到 j（含长度至少为 1 的路径）。可由邻接矩阵反复做布尔乘求出，也可直接按 Warshall 算法。

**关联矩阵**：n×m，行是点，列是边。起点写 1，终点写 −1，其余 0。看的是点与边。

**三条自检规则**

关联矩阵每一列之和为 0，且恰有一个 1 一个 −1。
行内 1 的个数是出度，−1 的个数是入度。
可达性矩阵中若有若干行完全相同，这些点一定属于同一个强分图。

## 四、手算时真正会出错的地方

**箭头方向读错**。教科书印刷图上的箭头很小，尤其双向边和斜线。读错一条，可达性矩阵整块变。校核办法是看某点的入度：如果按自己的读法算出某点入度为 0，但图上明明有箭头进它，方向就读反了。

**少写一条边**。矩阵里漏 1，是最常见的失分点。自查：行内 1 的个数应等于出度，列的 1 之和应等于总边数（有向图）。

**把互斥和对立、强连通和单向连通混为一谈**。强连通要求互相可达，单向只要一方可达，后者弱得多。

**分图不划分**。强分图一定不重叠且覆盖全部顶点，单向分图可以重叠、也可以有顶点不属于任何单向分图的极大链。

## 五、一个可复用的检查流程

一，把边全部列出来（起终点各写一次），数一数总数。
二，逐行填邻接矩阵，填完用出度校验。
三，算可达性：每点做一次广度优先，记下能到哪些点。
四，找强分图：互相能到的归一块。
五，缩点画 DAG，找最长链得单向分图。
六，关联矩阵逐条边填一列，用列和为 0 校验。
