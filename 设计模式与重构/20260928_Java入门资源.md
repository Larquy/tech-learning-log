## 学习顺序（按"服务课程"排，不按教程目录顺序）

1. **语法扫盲**（半天）：变量、循环、方法、数组 —— 有 C/C++ 底子可跳读
2. **面向对象核心**（重点）：类与对象、继承、多态、**接口 `interface`**、抽象类、包与访问控制（`public/protected/private`）
   → 设计模式的所有例子都建立在这一层
3. **泛型 + 集合**：`List` / `Map` / `Set`，泛型的基本用法
4. **Lambda 与 Stream**：现代 Java 写法的"语法糖"，设计模式里常用
5. **异常**：`try/catch`、checked 与 unchecked 的区别
6. **然后直接进入设计模式实践**：用工厂、单例、策略这几个模式边写边补语法（比从头刷完教程再动手快得多）

## C/C++ → Java 的关键差异（省时间靠这张表）

| # | 差异 | 说明 |
|---|---|---|
| 1 | **无指针，有引用 + GC** | 不用手动 `free`，也没有指针运算 |
| 2 | **方法默认可被覆写** | 相当于"全虚函数"，不想被覆写要加 `final` —— **与 C++ 相反** |
| 3 | **`interface` 是独立类型** | 可多实现，但只能单继承 |
| 4 | **一切都在类里** | 没有全局函数；入口固定 `public static void main(String[] args)` |
| 5 | **`String` 不可变** | 比较内容用 `.equals()`；`==` 比的是引用（必踩的坑） |
| 6 | **泛型不装基本类型** | 要写 `List<Integer>` 而非 `List<int>`（自动装箱）；异常分 checked/unchecked，checked 必须处理 |
